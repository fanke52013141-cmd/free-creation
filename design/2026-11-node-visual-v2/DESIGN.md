# Canvas Studio 节点视觉优化方案 v2.1

日期：2026-11-04。实施接续于 2026-11-05；2026-11-06 按用户桌面参考 HTML 接续卡面材质、悬浮光、按钮与选中动效（见 §4 与 REVIEW.md 的 2026-11-06 小节）。当前实现与验证见 REVIEW.md，冲突参数以 NODE_UI_STANDARD.md §23（2026-11-06 视觉接续）为准。

> **本轮定下的设计约束**：先建立逐节点状态和操作清单，再逐个优化。连接点必须独立悬浮，与卡边净距20px；图片文件工具移到标题、底部六操作同条；空态图标64px；步进箭头透明无子背景；引用保持真实单排缩略图与详情。详见 [STATE_MATRIX.md](./STATE_MATRIX.md)。300仅为无额外内容的默认高度，不得压缩引用或结果。产品功能保持原样；下文已合并本轮修正，不再沿用前版40px空态或贴卡端口。

## 1. 设计任务与边界

让目前节点的视觉更轻，同时保留完整功能、同类辨识度和全部业务状态。沿用现有六大分类、节点 ID、节点专属身份色和功能布局；不将节点全部改成一种绿色，不用一张静态效果图替代状态设计。

已核对：`NODE_UI_STANDARD.md` §19–21、`NODE_COLOR_SPEC.md`、`node-ui-tokens.ts`、`node-status.ts`、菜单分类清单，以及图片五节点、文本、文件、网址、视频素材/生成/转换的相关呈现代码。声音、AI、数据节点本轮完成系统层适用规则与清单；其每项正文和弹窗尚未逐项视觉验收。

本提案取代前两张 AI 效果图中的功能删减、常驻说明和按钮配色建议。那些图片只是风格探索，不能作为功能清单。

## 2. 视觉核心

1. 一张中性卡片、一套材质；正文按留白分组，不套彩色子卡。
2. 编号在前、图标在后、名称紧随；编号醒目，类型图标清楚。
3. 颜色用于身份和真实状态；不再用绿色按钮表示“主操作”。
4. 同类节点通过**固定轮廓、名称、身份色、专属正文结构**共同识别。
5. 空态不能假装已有结果；有内容后展示真实内容和真实动作。
6. 操作不因减轻视觉而被删掉，说明不因填满空白而被加回来。

## 3. 外壳与几何

### 3.1 标题区

建议结构：`醒目编号 | 类型图标 | 名称 | 输入输出/设置入口 | 运行状态 | 运行入口`。

- 编号沿用节点实际编号，不因切换分类、重新排序或修改模型而重编号。本提案不改变现有编号的存储机制；持久化改造若有需要另立功能任务。
- 标题并入完整卡片外壳，取消彩色折角。仍保留现有说明/设置、状态与运行入口，不以省略号把它们一起藏起来。
- 名称仍允许原有重命名；名称截断时完整名称在悬停/聚焦可读。
- 可执行节点保留运行入口，素材/只读节点不伪造可运行状态。
- 头部文字中性白；编号统一浅青，**不是分类色或运行状态色**。

### 3.2 默认尺寸

| 项目 | 提案值，100% 画布 CSS px |
| --- | --- |
| 完整节点默认外框 | 340 × 300，含标题区 |
| 标题区 | 36 高 |
| 正文内边距 | 左右/顶部 12，底部 8 |
| 外壳圆角 | 12 |
| 同排控件间距 | 6；裁剪独立比例按钮 8；图片快捷操作 4 |
| 配置行间距 | 8 |
| 分组间距 | 12 |
| 输入、下拉、数值步进器 | 28 高，6 圆角 |
| 常规操作按钮 | 32 高，7 圆角 |
| 正文/主按钮文字 | 12 / 600，行高 18 |
| 标题文字 | 14 / 600，行高 20 |
| 编号 | 16 / 700，等宽数字 |
| 标题图标 | 17，统一线性语言 |
| 空态身份图标 | 64，居中、无底板、无边框 |
| 端口可见圆点 | 8，交互热区 24；圆点边缘到卡边净距 20，圆心距卡边 24 |

300 高来自生图完整默认表单的布局预算：36 标题 + 20 上下内边距 + 28 模型行 + 28 选项行 + 100 提示词 + 24 三处间距 + 32 动作 + 32 余量，实际使用 flex 分配余量，不能将余量重复计为需求高度。输入区至少 72 高，默认约 100–120。

这是**新外壳总高度**，不是把现有 260 正文再叠一个 300 外壳。正式实施须统一尺寸真值与自动测量后重新验证，不能仅修改 CSS 的 min-height。

所有普通节点初始采用同一默认档；图片、裁剪、拆分不因素材像素或行列数变化自动撑高。生成类、文本等按真实内容扩展，建议完整外框档位 300 / 360 / 420 / 480，视频富配置最大档 600；这些是从现行档位加标题预算后的提案，须以真实正文 QA 定稿。手动大小、旧项目自定义尺寸不被批量重置。轨道线等已有自由尺寸节点继续使用自己的专项规范。

### 3.3 内容与操作区

- 标题与正文之间仅一条弱分隔线；正文分组不画下划线。
- 预览使用剩余空间并保持比例。拆分显示真实分格线和格号；不能把一张图压缩成九个无来源的小缩略图。
- 底部只存在实际动作。有一个动作占满，有两个等分；多个素材快捷操作沿用紧凑工具条。
- 无动作不预留 footer。拆分不增加“拆分图片”底部按钮。
- 配置区、引用区、结果区只有实际存在时才占位；引用单排规则保持。
- 正文滚动和全局隐藏滚动条规则不变；不能用 overflow:hidden 隐藏真实内容或输入项。

### 4.2 身份色

沿用 `NODE_COLOR_SPEC.md` 的逐 ID 原色。输入玫红、图片绿色、视频蓝色、声音紫色、AI 青蓝、数据橙色保持。

**允许位置**：标题类型图标、空态身份图标、既有协议允许的端口色。图标必须始终按相同节点 ID 取色，不能空态绿色、有内容白色。

**禁止位置**：卡面、折角、输入框、文字按钮、正文分组框、整张卡阴影。取消折角不意味着取消身份。

`#3CDDE3`（accent）仅用于鼠标跟随面光、边缘光、选中流光与字段聚焦描边，**不替代节点身份色**；卡面、按钮、输入框仍不得按节点分类色染色。

端口既有来源色继承、拖线兼容与中性连线规则保持；节点类型色不覆盖端口实际数据语义。静止端口不发光；可连接时以清晰轮廓提示，不叠大面积模糊光晕。

### 4.3 按钮

- 生成图片、导入图片、打开工作台、裁剪图片、配置视频截取等，使用**同一中性材质**：渐变面 `linear-gradient(180deg,#1d2430,#161b24)`、1px `#333b48` 描边、32px 高、10px 圆角、12px/600 中性白文字。
- hover 切换为 `linear-gradient(180deg,#242b37,#1c222c)` 并加 `0 6px 16px rgba(0,0,0,.35)` 阴影；按下 `scale(.985)`；减少动态效果时去掉按压缩放。
- 主次依赖位置、宽度、文字和是否为工具图标区分，不再依赖绿色/白色填充变化。
- 单选比例项正常为深灰，选中为较亮中性灰 + 明确轮廓/勾选，仍不染成节点绿色。
- 禁用采用明确 disabled 行为与禁用材质；缺少条件的原因在聚焦/悬停或提交时显示，不常驻教学文案。
- 危险动作在明确的删除/清空确认位置使用危险红，不借图片绿或分类色。

### 4.4 状态色

运行蓝 #78B8F8、成功绿 #75C59B、警告黄 #E0B970、错误红 #ED8E8E。只用于状态区的图标/必要文字或相关字段错误，不改变类型图标、编号、整张卡或按钮色。状态永远有文字或图形配对，不靠色盲用户识别颜色。

## 5. 辨识度规范

### 图片五节点

| 节点 | 唯一轮廓语义 | 空态 | 有输入/内容 |
| --- | --- | --- | --- |
| 生图 | 图片 + 小星标，星与主体分开 | 直接展示完整生成表单 | 原表单 + 真实引用、生成记录与结果；保持已有能力 |
| 图片 | 单张山景画框 | 64px 画框 + 底部导入图片 | 单张完整预览 + 底部六操作工具条，文件定位/路径复制在标题 |
| P图 | 画框/方框 + 编辑笔 | 64px 编辑轮廓 + 打开工作台 | 修改说明、来源/结果、原图对比、多结果及原有后续/文件操作 |
| 裁剪 | 两条交错直角裁切线 | 64px 裁切轮廓；不伪造图片或比例条 | 原图 + 可操作裁剪框、独立比例项、精细框选/裁剪图片 |
| 拆分 | 规则宫格 + 分格语义 | 顶部行/列/面积 + 64px 宫格轮廓 | 同一原图上显示真实宫格与格号；标题运行 |

图片区别于拆分：画框 vs 宫格；单图预览 vs 带格号的分割预览；素材快捷操作 vs 顶部三参数。不能两者都使用相同山景缩略图且只改标题。

图标继承当前专属图形语义，统一线性语言、转角与端点；标题线宽约1.75–2，64px空态图形采用较轻的光学线宽，不直接放大成粗线团。实尺寸17px仍要分清。原生自定义节点图标优先继续使用，方案预览里的通用线性图标只演示轮廓分工，不替换产品图标资产。

## 6. 状态模型：三个维度，互不替代

### A. 内容状态

空态 / 有输入待执行 / 已有结果 / 编辑中。必须分别设计，不能拿已有结果填充默认空态。

### B. 画布交互

默认 / 悬停 / 选中 / 拖动 / 焦点。悬停显示鼠标跟随面光（`rgba(60,221,227,.14)`，半径随卡尺寸 `max(260px, 对角线×0.55)`）与边缘光（`rgba(120,232,238,.55)`），上浮 3px；选中只增加 75% 青色外轮廓 + 8 秒一周的 1.5px 锥形流光，不染整卡、不改按钮；减少动态效果时停用流光与上浮。拖动不改变文字对比度；单击选择、拖动与双击编辑遵循 §19。键盘焦点应可见，公共下拉现有外部关闭与焦点规则保持。

### C. 执行状态

| 真实状态 | 必要呈现 | 操作规则 |
| --- | --- | --- |
| idle | 不显示“尚未运行”占位句 | 可用性按真实前置条件 |
| pending / queued | 时钟 + 等待执行/已排队 | 防止重复提交，沿用现有取消能力 |
| running | 小旋转图标 + 执行中 | 禁止重复执行；有真实进度才显示百分比，不编造进度 |
| success | 小勾 + 执行成功，可低调保留在状态入口 | 结果立即可见，不让按钮长期变绿 |
| failed | 错误图标 + 执行失败；一行可行动的原因 | 保留原内容/配置/旧结果，允许原路径修复和重试 |
| cancelled | 中性停止符号 + 已取消 | 不显示为失败或成功 |
| cached | 缓存符号 + 使用缓存 | 与真实新执行结果区分 |

没有模型、缺输入、格式错误属于前置条件/校验，不伪装成一次执行失败。校验文字只在相关字段或操作发生后出现。

旧结果与新执行并存时，保留旧结果并标明新任务正在执行/失败；不能把旧图显示成这次生成成功。状态值取公共运行记录，不由动画结束或 UI 本地计时器决定。

## 7. 字段与说明

### 删除

常驻“支持 PNG/JPG/WebP”“支持 1–10 秒”、重复“输出参数/宽高比/分辨率/数量”大标题、节点用途介绍、占位“0 字”、无结果时的结果分区。

### 保留

- 值本身清楚的控件：`1 张 / 16:9 / 1K`、`16:9 / 1s / 1080p`，不加可见冗余标签；必须保留 aria-label 与必要工具提示。
- 无法凭数字判断的控件：`行数 / 列数 / 面积`、`透明底`、`生成同步音频`。不能只留下三个“3 / 3 / 100”。
- 名称、网址、真实文件名等用户数据；必要时显示，不为填充版面新增 MIME/格式说明。
- 模型能力决定配置项是否存在，范围限制放进真实选项，校验失败时再说明；移除说明不移除约束。
- 模型不支持透明底时不显示该控件；生视频同步音频选项仅在支持时出现。

## 8. 操作保真矩阵（本轮重点）

| 节点/状态 | 必须保留的操作与内容 | 不允许的改法 |
| --- | --- | --- |
| 生图 | 供应商、模型、数量、画幅、分辨率、能力支持时的透明底、提示词、真实引用/引用提及、生成与结果记录 | 删除透明底、用示意参数替换实际模型能力 |
| 图片空态 | 导入图片 | 新增静态支持格式说明 |
| 图片有图 | 裁剪、拆分、生图、P图、生视频、替换，以及已有文件辅助操作 | 仅保留一个“打开工作台” |
| P图空态 | 原有工作台入口与真实接线校验 | 把空态画成已完成结果 |
| P图结果 | 调整修改、对比原图、修改说明、后续动作、文件操作与已有多结果选择/历史能力 | 因简约删掉修改说明或原图对比 |
| 裁剪待执行 | 拖动裁剪框、完整比例集合、精细框选、裁剪图片 | 只留一个“应用裁剪”；把多个比例连成难分辨的条 |
| 裁剪结果 | 调整裁剪、文件操作及已有重新裁剪入口 | 把原图裁剪框直接当最终结果 |
| 拆分 | 行/列/面积、宫格预览/格号、标题运行、既有输出投影与展开 | 新增“间距”替换面积；新增多余底部运行按钮 |
| 文本 | 输入/编辑、保存/退出、正文预览 | 用常驻表单替代原有编辑状态、不保留保存语义 |
| 文件 | 导入、已导入名称与可解析正文、替换、系统打开及已有后续/文件操作 | 只展示文件大图标 |
| 网址 | 配置；有内容时名称、URL、打开网址；改名仍同步标题 | 虚构网页抓取/读取能力 |
| 视频生成 | 模型、生成模式、描述、真实引用、画幅/时长/分辨率、能力支持时同步音频、生成 | 删除模式或能力相关项；新增常驻范围说明 |
| 视频素材 | 导入；有内容后替换、视频截取、抽帧及已有辅助操作 | 用一个“配置视频”覆盖所有动作 |
| 截取/抽帧 | 原有配置工作台、时间与预览、输出后续操作 | 在卡面重新发明一套不完整播放器 |
| 深度/白模 | 原有生成与结果；白模质量/效果和旧版本升级入口 | 只展示空态大图标而丢配置 |

## 11. 验收标准

- 32 节点同一外壳、文字按钮、输入材质；无私有渐变、彩色卡面或发光点。
- 相同 ID 的标题图标、菜单图标、空态图标身份一致；有内容时不突然变白。
- 图片与拆分在 100% 及 75% 实际画布缩放下，同时看轮廓、正文结构与文字能区分；不能只验色差。
- 空态无虚构素材、无支持格式/范围说明；有内容态所有原有快捷操作仍可见且原回调可达。
- 无底部动作的节点没有操作栏占位；拆分行列变化不改变默认外壳高度。
- 选中、排队、执行、成功、失败、取消、缓存，以及无模型/缺输入分别验收；不能一张成功截图代表全部。
- 标题、空白与只读内容可以选择/拖动；文本双击编辑、Tab 聚焦、下拉外部关闭、端口与媒体双击预览保持。
- 默认/展开/手动尺寸、长名称/长模型名、旧项目恢复、实际引用和多结果集合均需检查。
- 可操作控件轮廓与语义图标对真实背景目标 ≥3:1，正常正文 ≥4.5:1；分类色复算继续使用现有色板脚本。
