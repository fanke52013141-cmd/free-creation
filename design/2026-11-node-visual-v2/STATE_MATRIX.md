# 节点状态清单与逐节点视觉接续 v2.1

日期：2026-11-04。性质：设计规格，**不是产品实现/全状态验收完成证明**。本轮只修改设计资料与对话样例，不修改应用功能或回调。

## 1. 本轮优先裁决

1. **连接点独立悬浮**：可见圆点 8px，与卡片外沿的最近距离 20px；中心距卡边 24px；24px 命中区也不贴卡。无连接短杆、底板、耳朵或外框拼接。选中轮廓不把端口一起包住。保留原端口数量、契约、展开和继承语义，连线终点要同步到圆点中心。
2. **图片操作收敛**：有图片时，定位文件、复制文件路径放标题右侧。正文保持完整图片预览，底部一条连续中性工具栏容纳裁剪、拆分、生图、P图、生视频、替换。六个动作全部可见，不折进更多菜单，不让两枚文件图标单独占一行。
3. **空态有清晰重心**：身份图形从 v2 的 40px 调整为 64px，保持细线和专属颜色；按有效正文空间居中，不额外插入说明。P图保持底部打开工作台；空态不能伪造成已出图。
4. **数字步进器只有一个外壳**：右侧上下箭头透明、无背景、无子描边、无阴影；悬停只提高箭头对比度。隐藏原生 spinner，以现有公共 NumberStepper 的键盘、步长、范围和回调为准。
5. **P图功能不重构**：卡片与工作台分工完全沿用现有实现。工作台的工具、模型、参数、说明和提交；卡片的修改、对比、历史、输出和文件操作都保留。不得用“打开工作台”替代有结果状态的完整功能。
6. **引用样式优化**：保留单排 36px、48×36 缩略图、+N、真实顺序与现有增高规则。新样式是轻中性外壳和真实缩略图，不能退化成一句“参考图片 · 1”。无引用不占位，裁剪/拆分主预览不重复引用。

尺寸均为 100% CSS px。20px 是可见点边缘到卡边的净距，**不是圆心距**。实现时不能只把圆点绘制位置移走而仍把真实连接锚点留在卡边。

## 2. 状态拆分与完成标准

每个节点分别检查四轴：

- 内容：空、已配置、有效输入、编辑、已有结果、多个结果、源输入失效但仍有旧结果。
- 交互：默认、悬停、选中、拖动、键盘焦点、下拉展开、双击预览；不能把“选中”当成内容状态。
- 执行：未运行、等待、排队、执行、成功、失败、取消、缓存。仅向支持该执行路径的节点映射；素材导入错误不虚构成模型执行失败。
- 依赖/引用：无连接、有连接无输出、单项、多项、混合类型、0/false/空值、媒体读取失败、移除/断线、超过可见数量。

每个有效组合需记录：**出现条件 → 可见内容 → 可用操作 → 操作目标/保存语义 → 返回状态 → 产品内验证证据**。不适用的组合标 N/A，而不是给所有节点套“空/输入/结果”三档。

以下是设计必须覆盖的清单；“清单已列出”不等于所有分支已实施或产品内验收。

## 3. 图片五节点：逐项状态与原功能

### 3.1 图片（image）

依据：`image.tsx`、`shared.tsx:ImageContinuationActions/MediaFileActions`、Spec image@3。

| 状态 | 正文 | 必须可达的原操作 | 状态保持 |
| --- | --- | --- | --- |
| 空 | 64px 图片图形；底部导入图片 | 导入 | 选择文件后沿现有媒体导入流程 |
| 选择文件/导入中 | 原空态或旧图片；导入/替换中 | 防重复提交 | 取消选择不清空原图片 |
| 有图 | 保持比例的完整图片；底部六项工具条 | 裁剪、拆分、生图、P图、生视频、替换；标题定位文件/复制路径；双击预览 | 下游操作仍创建原节点与真实边 |
| 替换中（已有图） | 旧图保留；替换控件忙碌 | 不允许重复替换；其他操作按当前逻辑 | 新文件导入成功后才更新引用 |
| 导入失败 | 原空态/原图不变；按需错误 | 重试原导入/替换 | 不额外生成失败资产 |
| 图片不可读 | 失败占位，不用别的图片顶替 | 替换、已有文件操作按真实 mediaId 条件 | 不伪造预览成功 |
| 预览 | 既有统一媒体预览 | 缩放、关闭等既有操作 | 不修改节点内容 |

图片 Spec **没有输入端口**，只有 out-image。前版样例给每张卡都画一进一出不准确，本轮修正；视觉不能创造不存在的业务端口。

### 3.2 生图（image-gen）

| 状态 | 必须呈现 | 不得改变 |
| --- | --- | --- |
| 无可用模型 | 原 NoModelHint 与模型设置入口 | 不展示一套假模型选项 |
| 已有模型/无引用 | 供应商、模型、数量、画幅、分辨率、能力允许的透明底、提示词、生成 | 参数能力/顺序/回调按现有实现 |
| 单项/多项/混合引用 | 真值缩略图或摘要，单排 +N，提示词引用提及 | 顺序和数量约束不因折叠变化 |
| 某引用不可读 | 该项错误占位 + 详情 | 不用示例素材替代、不自动跳过 |
| 排队/执行中 | 保留表单；真实状态；防重发 | 不编造百分比或自动成功 |
| 成功 | 原真实输出路径与记录；表单继续可用 | 不因为效果图好看就给生成节点发明另一套卡内结果区 |
| 失败/取消/缓存 | 各自真实终态；配置与已有结果保留 | 不把旧结果标为新执行成功 |
| 模型变更 | 按真实能力调整选项 | 不删除隐藏配置或擅设新的默认能力 |

### 3.3 P图（image-edit）

依据：`image-edit.tsx:ImageEditBody/ImageEditSettings/ImageEditWorkbench`、`shared.tsx:MediaResultGrid`。

| 状态 | 卡片/工作台 | 必须保留 |
| --- | --- | --- |
| 无原图、无结果 | 大编辑身份图形 + 打开工作台 | 现有缺输入校验；不虚构预览 |
| 原图已接入、无结果 | 卡片继续作为工作台入口；真实引用按现行公共规则显示 | 不是简单“图片导入卡”，不在卡片伪造完成结果 |
| 工作台打开/标注 | 外部工作台，卡片不改造成一个阉割版编辑器 | 移动、箭头、矩形、画笔、文字、遮罩；红修改/蓝替换/黄保留；撤销、重做、清除 |
| 工作台遮罩/标注选中 | 原工具和对应参数 | 选择/移动/清理标注与遮罩，笔刷参数及原保存语义 |
| 工作台模型参数 | 原模型（含供应商归属）/画幅/分辨率及修改说明 | 能力校验、4000 字说明限制、真实提交路径；不额外发明供应商选择器 |
| 执行中、无旧结果 | 工作台/卡片按原提交流程；真实执行状态 | 不生成占位结果资产 |
| 单结果 | 完整结果预览、来源、修改说明 | 调整修改、对比原图（仅原图仍可用）、定位、复制路径、所有下游操作 |
| 修改说明编辑 | 原卡片内编辑区 | 失焦提交、Esc 恢复、Ctrl/⌘+Enter 提交；写回同一配置 |
| 原图对比 | 两张真实图片与明确原图/修改结果标签 | 原开关语义，不拿一句“对照样例”替代功能 |
| 多历史结果 | 当前输出 + 真实历史集合 | 预览、切换当前输出、删除非当前项、清空历史仅留当前；破坏操作继续确认 |
| 有旧结果、再次执行 | 原结果保留 + 新任务状态 | 不假装旧结果刚生成 |
| 有旧结果、新执行失败 | 原结果/历史/说明保留 + 真错误 | 原路径修复与重试，不清掉旧图 |
| 原图断开但已有结果 | 已有结果仍显示，原图对比按真实条件消失 | 不回退成纯空态，不假装仍能对比 |

这份列表是**功能保真约束**。视觉样例即使没有实现完整画笔算法，也不能被当作替换产品 P图的代码。

### 3.4 裁剪（image-crop）

| 状态 | 必须呈现/可达 |
| --- | --- |
| 无原图、无结果 | 大裁剪图形；不显示假比例预览或假按钮 |
| 原图就绪 | 原比例预览、可拖裁剪框、六个卡内常用比例、精细框选/裁剪图片 |
| 比例切换/拖动 | 独立有间距的单选项；原约束/坐标和框选逻辑 |
| 精细框选 | 完整比例集合、矩形/透视能力、坐标与结果预览按原工作台 |
| 执行中/失败 | 保留原图与参数；真实状态，不假装裁剪已成功 |
| 有结果 | 结果预览、调整裁剪、来源/文件操作、原重新裁剪入口 |
| 原图断开但有结果 | 旧结果保留；需要原图的操作使用原校验 |

### 3.5 拆分（image-split）

| 状态 | 必须呈现/可达 |
| --- | --- |
| 无原图 | 顶部行/列/面积；大宫格图形；原标题运行 |
| 原图就绪 | 一张原图上的真实分格/格号；参数不挪到不存在的新面板 |
| 调整参数 | 步进与直接输入；行 1–64、列上限 floor(64/行数)、面积 1–100；共享同一 config；分格边长按面积比例开平方缩放 |
| 原图预览 | 双击/键盘沿原完整预览路径 |
| 执行/失败 | 真状态；无新增底部运行按钮 |
| 已完成/选定输出 | 继续呈现原 Body 的源图分格；既有当前图/图片集合投影和展开能力保持 |
| 断线/源图不可读 | 不伪造源图；保留配置与真实结果记录 |

不能为了展示结果在拆分 Body 中擅自新增产品目前没有的“历史编辑器”；输出能力按既有投影/工作台机制呈现。

## 5. 引用优化：不变的功能与新的材质

- 无引用无空槽；单排 36 高、媒体 48×36；含多项时先留 +N 的位置。
- 容器中性深底、1px 轻灰边、6px 圆角；图片完整 contain，不做装饰裁切。
- 单图/多图可看到真实缩略图，角色和来源放详情；提示词等文本显示角色与摘要。
- +N 打开真实条目列表，能选中或进入每项详情；不让缩略图成为不可点击的装饰。
- 加载中保留该项固定尺寸；不可读显示该项错误符号，详情给原因。不能静默换图。
- 有连接但无输出不制造引用；0/false/空文本/空数组仍是有效值。
- 悬停 300ms/键盘聚焦打开、可移入详情、Esc/外部关闭的原语义不变；不因悬停执行模型。
- 有独立引用行时沿现行规则增加 44px 真实高度预算、再取高度档。**不能为了维持所有状态300高压缩掉提示词与功能**。无额外引用行的裁剪/拆分不重复增高。

## 6. 逐节点推进顺序与本轮边界

先完成状态清单与操作映射，再按：**图片 → P图 → 生图及引用 → 裁剪 → 拆分 → 输入 → 视频 → 声音 → AI → 数据**推进。

每个节点的评审包包含：原功能列表、全部适用状态、布局与颜色、回调/配置保持关系、真实尺寸截图与操作验收。确认当前节点后再沿同一规则迁移，不把同一张通用模板强套到所有 Body。

本轮视觉样例先覆盖图片五节点，可以逐个选节点、逐个选该节点适用状态。其工作台、导入、复制及执行只作视觉/局部交互演示，不连生产数据。完整业务不以演示样例代替。

日志及外部接入：不涉及；没有修改执行、网络、资产、数据库、持久化与接口。
