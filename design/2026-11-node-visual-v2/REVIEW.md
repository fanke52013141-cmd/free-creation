# 节点视觉 v2.2 实施与审查记录

2026-11-04。状态：源码已实施，等待用户视觉复核；未替换正在运行的安装版。

## 本轮实际改变

- 全部32个可创建节点接入公共外壳、内置36px标题、中性材质和统一控件；业务正文与工作台保留原代码。
- 编号/图标/名称均置于20px高居中容器，图标display:block，避免行内基线偏移；编号在图标前。
- 普通节点默认总高度300，展开360/420/480，视频富配置600；内置标题计入测量。旧显式手动尺寸保持原260下限，旧自动260迁入新默认。轨道线默认291/最小224为原255/188加36标题预算，原三轨可用空间保持；手动高度不按旧默认强制迁移。
- 端口核心8、命中区24、圆心外移24，真实连线共用偏移；20px可见净距，不贴卡、不发光、不带底板。
- 图片原六快捷回调保留，定位文件/复制文件路径经公共header portal移入标题；忙碌禁用语义保留。
- 图片/视频引用保留真实缩略图。文本、音频、文件、结构引用按来源编号+类型图标显示；例如01T。长正文仍可在原详情全文阅读、复制或播放；顺序和输入投影不变。
- 拆分宫格、抽帧单帧、截取双切点重绘；其余身份色不变。菜单/标题/空态共用现有Icon组件。
- 步进器箭头透明，裁剪比例独立留间距；视频参数移除重复可见标题，并补足aria-label。

续接定位先检查右侧相邻空位，使用 page bounds 处理分组坐标，再按占用避让。复制提示走公共顶部 toast。运行、数据端口和媒体保存沿用原公共路径，日志检查见 LOGGING_COVERAGE。

## 2026-11-06 视觉接续（参考桌面 HTML《画布卡片特效》）

用户提供桌面参考 HTML 作为基准，要求鼠标悬浮光效、卡面颜色、按钮样式、选中效果与生成中动效全部对齐；同时明确"生成中的星星出来太慢"，要求星星更快出现，并覆盖所有加载/生成中状态。

### 实际改动

- 卡面/控件按参考重构：卡面 `#1b202b→#151922` 纵向渐变、外框 `#252b36`、hover `#333b48` 且上浮 3px（阴影 `0 6px 18px rgba(0,0,0,.45)`）；输入底 `#0f131a`、描边 `#252b36`/hover `#333b48`/聚焦青色 50%；按钮渐变面 + 10 圆角 + hover 阴影 + `scale(.985)`；正文/辅助/禁用文字 `#e7ebf2`/`#8b95a5`/`#5d6675`；编号 `#38bdf8`。
- 悬浮光与选中：鼠标跟随面光 `rgba(60,221,227,.14)/.07`（半径 `max(260px, 对角线×0.55)`，边缘光半径 0.62×、`rgba(120,232,238,.55)`）；选中 75% 青色外轮廓 + 8 秒一周 1.5px 锥形流光，减少动态效果时停用。浅色主题保留原材质。
- 加载/生成中：以共享星辰光场替换原蓝色点阵+波浪，星星在开始后 ≤600ms 全部出现（进度只做轻微扫光），覆盖启动、项目列表、资源详情、聊天、导演台、运行时间线、视频 AI 卡、节点运行遮罩；见 `docs/GENERATION_LOADING.md`。
- 追溯线：可悬浮出剪刀、剪刀写 `meta.artifactLinkHidden=true` 隐藏（文案「隐藏追溯线」），仍不可点击/右键选中，不删除数据边；隐藏仅可撤销恢复，暂无 UI 恢复入口（已知缺口）。
