---
name: image-generation
description: 用户明确要求画图、生成图片、插画或海报时调用已配置的图片生成 API。
---

调用 generate_image 工具生成一张图片。根据当前用户要求和对话上下文整理完整提示词，不添加无关主题。
用户只是咨询图片、分析图片或讨论 API 时，不调用生图工具。
分辨率由界面选择，默认 1K，可设置 4K；质量始终为最低档 low，禁止擅自升档。
一次用户发送最多调用一次 generate_image；失败后说明原因，不自动重试收费任务。
工具成功后，系统会直接在对话页面显示真实图片附件并提供预览和下载。
最终回复简短确认结果；不要编造图片 URL、Markdown 图片链接或声称生成了工具未返回的图片。
当前工具是文生图，尚不支持修改已有图片，不要声称已完成图片编辑。
