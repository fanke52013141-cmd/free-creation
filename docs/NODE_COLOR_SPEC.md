# 节点分类与图标颜色规范

版本：1.1 · 制定日期：2026-10-05 · 配色实施日期：2026-10-05

状态：身份色已实施。33 个节点 ID 已纳入统一色板，28 个可创建节点已通过浏览器颜色验收。本文的验收范围是节点身份色，不代表全部界面样式均已完成浅色主题适配。

## 1. 基本规则

颜色分两层：**分类主色帮助识别业务领域，节点变体帮助区分同类功能**。同类节点使用同一色系内的色相与明度变化，不能全部使用同一个颜色，也不能仅靠降低透明度区分。

分类以 `src/renderer/src/canvas/palette-categories.ts` 的用户可见分类为准，不以旧 `NodeTypeSpec.category` 或输入/输出端口类型决定。一个节点在工具栏、创建菜单、搜索结果、节点卡片和详情面板中必须保持相同身份色。

本文是节点身份色的规范来源；现有文档或代码注释中“视频为青、音频为蓝、对话为紫”等旧规则由本文替代。布局、端口继承行为和状态交互仍遵循现有呈现规范。

## 2. 五大分类主色

以下 HEX 为深色界面的目标前景色。分类入口使用主色，具体节点使用第 3 节的固定变体。

| 分类 ID | 界面分类 | 主色名称 | 主色 HEX | 可用变化 | 边界 |
| --- | --- | --- | --- | --- | --- |
| input | 输入与 AI | 玫红 | `#F472B6` | 浅玫红、蔷薇、莓红 | 不使用声音的紫色或视频的蓝色 |
| image | 图片创作 | 翠绿 | `#4ADE80` | 黄绿、翠绿、青绿、蓝绿、深绿 | 蓝绿仍需明显偏绿，不进入视频蓝 |

## 4. 界面使用规则

1. 分类入口用分类主色；节点图标和卡片强调条用节点变体，前景默认 100% 不透明。禁止各入口自行硬编码另一套颜色。
2. 同一节点的悬停、选中、运行、成功和失败不会改变身份色。选中使用独立轮廓，运行使用动画或状态标记，成功/警告/失败使用独立状态图标及文字。
3. 图标底板可使用身份色的 12% 透明度，悬停底板可用 18%；这只是背景层级，不是节点之间的颜色差异。大面积卡片背景保持中性。
4. 标题和正文使用主题文字色，不整段染成身份色。不得以白色通用 SVG 覆盖声音等分类的图标色；单色图标优先继承 `currentColor`。
5. 静止端口及连接后的来源色继承继续遵循现有端口协议。拖线兼容提示的 `PORT_COLORS` 是数据类型色，不能用它替代节点身份色。正式连线保持现有中性线样式。
6. 错误红、警告黄、成功绿、品牌选中色属于状态/交互语义。图片绿色不代表成功，流程橙色不代表警告；必须通过位置、图形与文字区分。

## 5. 可辨识性与主题验收

本规范不承诺仅靠颜色区分所有节点。图标轮廓、节点名称必须同时可见；色觉差异用户不能被迫只靠色相识别功能。

- 在真实界面背景上测量图标与相邻底色的对比度，产品验收目标至少 3:1；承载文字时，普通文字目标至少 4.5:1。不能只在白纸色板上判断。
- 按实际 16px 标题图标、18px 工具图标和 20px 分类入口检查，不能只看放大的色块。
- 同类节点需在实际菜单中并排检查色相、明度和图标差异；若难以区分，先调整该类变体，不得随意借用别的分类主色。
- 深色、浅色主题分别验收。本文 HEX 是深色身份色；图标前景由 `nodeIconColor` 和 `--node-identity-strength` 统一生成。深色为 100% 原色，浅色为 55% 原色与 45% `#17232D` 的 sRGB 混色。正文身份图标使用相同公式，浅色图标底板使用 12% 身份色与主题卡片底色的混色。不得在不同入口分别猜测浅色值。
- 深色主题中的“深绿/深蓝/深紫”是相对同类更深，不是接近黑色；对比度不通过时，应调整亮度后更新本表。
- 检查正常、悬停、选中、禁用及错误态；禁用同时提供交互禁用与明确提示，不只降低透明度。

## 6. 新增节点必须遵循的流程

1. 先确定五大分类中的唯一归属，再挑选颜色；AI 能力不是独立色系，按其主任务分类。
2. 在本文件新增节点 ID、名称、变体与 HEX，并同步用户可见分类映射。
3. 优先在本类色系内分配未使用的变体，禁止随机色、自动轮转色和散落在组件中的十六进制常量。
4. 色阶已密集时，允许同一功能子类复用已有变体，但必须通过不同图标及名称区分，并在表中注明复用原因；不要无限制造肉眼难辨的新色。
5. 统一在注册表 `NODE_ACCENTS` 维护节点颜色，节点 Spec 引用该值，消费者引用 `spec.color`；图标前景通过 `nodeIconColor(spec.color)` 适配主题。分类主色统一维护在 `PALETTE_CATEGORY_META.color`，不能在每个菜单复制一份。
6. 提交前核对：类别正确、全入口一致、没有白色或灰色覆盖、对比度通过、同类并排可辨；附实际主题截图与测量记录。
7. 改分类主色属于规范变更，需先更新本文版本和迁移说明，再同步该类所有节点。改名称或重排列表不得改变颜色。
