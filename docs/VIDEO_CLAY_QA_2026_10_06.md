# 白模视频 v2 优化与验收记录

日期：2026-10-06。规范：[VIDEO_CLAY_RENDERING_STANDARD.md](./VIDEO_CLAY_RENDERING_STANDARD.md)。本轮完成既有 Small 模型上的渲染、稳定处理、推理质量与产品接入；完整三维重建和更大模型未作为已实现能力。

## 改动与视觉裁决

原实现为归一化深度的二维梯度 + 单方向漫反射，容易突出轮廓浮雕边。现用透视可见表面法线、双边滤波、主光/补光/半球环境光、局部环境遮蔽、哑光白反射与 gamma。切镜分段推理与归一化，运动对齐后的历史融合拒绝遮挡变化、越界和不一致区域。

同源 2 秒人物片段，12fps，24 帧，仅只读截取用户已有视频，原媒体未改动。比较保留原画、旧渲染、相同深度的新渲染、标准档新渲染。旧渲染对比栏使用相同推理深度隔离材质算法；另外真实 IPC 跑了 v1 原推理/渲染，独立证明历史分支可用。

已查看开头、中段、末段并排图：人物衣物与桌面明暗更连续，粗重浮雕轮廓减弱；人脸仍缺乏充分五官几何，细边部分还有深度估计与近似遮蔽造成的瑕疵。不能据此宣称达到完整三维白模。头发、细杆、多人快速交错和跨场景素材的深度恢复还需扩大真实样片评审；合成测试不替代这些视觉结论。

## 五轴代码审查与日志影响

正确性：v1 原数学及推理尺寸保留；v2 相对深度只映射艺术化可见表面，历史融合按运动与切镜拒绝；帧数、音轨、独立资产及恢复有真实证据。

简洁性：材质/几何/时序封装为独立纯 Python 模块，runner 负责编排；配置解析集中共享，卡片与侧栏复用同一选项组件。

架构：端口及契约保持，配置版本显式；复用 executor、IPC、视频编码与项目保存，没有组件直调模型或隐藏输出。

安全：只读原媒体，隔离验收项目，无收费模型调用；不把数据库、凭据、源项目或原帧写入 Git。SDPA 不添加依赖下载。取消仅针对当前受控子进程树。

性能：光流引导图长边 256，历史只保留一帧；SDPA 避免巨大显式注意力矩阵；推理帧数沿用 1800 上限。长视频的整体内存占用仍受现有批量解码/推理设计影响，本轮短样片不能保证 1800 帧的峰值。

执行版本与结果保存复用 ctx.trace 和公共运行器开始/终态；不重复记录终态，不新增源视频正文/路径/配置全文诊断。worker 内部各阶段 JSON 仍未单独持久化成事件，仅保留现有协议与失败处理；此边界不宣称全链路阶段可查询。
