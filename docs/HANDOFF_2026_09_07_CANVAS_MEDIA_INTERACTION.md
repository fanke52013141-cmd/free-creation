# 2026-09-07 画布媒体交互与图片工作台优化交接

本批次响应画布验收反馈，聚焦于可见的几何稳定性、媒体工作流的可理解性，以及图片标注工作台的可操作性。

## 已交付

### 画布与连接

- 节点输入/输出端口改为卡片外侧的较大虚线圆环，连线几何锚定在端口中心；释放到外侧输入端口也能可靠命中。
- 选中节点后的运行按钮固定在卡片右上角，不再和状态圆点重叠。
- 分组轮廓的边距、标题位置、圆角和字体均按 tldraw 相机缩放同步计算。缩小画布时，不会再因固定屏幕边距形成细长、变形的分组框。
- 拆图结果展开为节点时，按原始行列摆放；旧的纵向展开记录会在下一次展开时进行一次性重排，避免九张图形成过高的分组。

### 图片与生成状态

- 所有节点内的图片/媒体结果预览统一为**双击打开**；单击只保留为选中节点。为兼容 tldraw 的 pointer capture，画布在第二次 `mousedown` 时将预览请求转发给真实媒体元素。
- 图片拆分的结果网格使用实际列数，缩略图采用 `contain` 完整展示，并显示 `R行 · C列`；100% 宫格计算有测试保证无重叠。
- 浏览器演示媒体层支持裁剪、拆图、生成、刷新后资产恢复；生成结果清楚标注为“浏览器演示生成 · 已完成”，不再把 `mock-relay` 暴露成状态信息。
- 节点执行中的状态层明确区分图片生成、图片修改、拆图、裁剪和视频生成，并显示转动加载图标及当前操作说明。浏览器演示生图加入短暂异步过程，便于验收此状态。

### 图片修改工作台

- 工具栏使用独立的移动、箭头、矩形、画笔、文字和遮罩图标；图标与文字垂直居中。
- 新增“移动”工具：可命中并拖动箭头、矩形、画笔轨迹、文字及已启用遮罩的笔划；选中对象有高亮，移动前会给出明确提示。
- 箭头头部改为更长、更尖的三角形，浏览器 SVG 预览与主进程导出的标注参考图保持一致。
- 画笔与遮罩均提供大小调节；遮罩保留启用、反选、清空等原有能力。

## 人工验收建议

1. 建立 3×3 拆图并展开为节点，确认卡片网格与画布节点网格均能看清各格。
2. 给图片修改工作台依次添加箭头、矩形、画笔、遮罩，再使用“移动”拖动每种标注；确认画笔/遮罩大小控件符合预期。
3. 对图片、生图、裁剪、拆图的缩略图分别单击和双击；单击应只选中，双击才打开预览。
