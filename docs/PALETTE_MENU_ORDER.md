# 节点菜单排序

默认顺序按常见创作流程的使用频率估计，尚未使用实际点击统计。左侧一级、二级菜单和拖线创建菜单共用配置。

一级：图片创作 → 输入与 AI → 视频创作 → 声音创作 → 流程与高级。

二级顺序：

| 分类 | 从常用到进阶 |
| --- | --- |
| 图片创作 | 生成图片、图片资产、P图、图片裁剪、图片拆分 |
| 输入与 AI | 文本、AI处理、AI对话、文件、网址 |
| 视频创作 | 视频生成、视频资产、视频截取、抽帧、深度视频、白模视频 |
| 声音创作 | 语音合成、音频、语音克隆、音色设计、声音调整 |
| 流程与高级 | 分镜板、数据处理、JSON、结构数据、循环、3D预演台、代码 |

修改 `src/shared/palette-menu-order.ts`：调整 `DEFAULT_PALETTE_CATEGORY_ORDER` 的数组位置即可修改一级顺序；调整 `PALETTE_NODE_GROUPS` 各数组中节点 ID 的位置即可修改二级顺序。修改后重新构建应用生效。只调整位置，不改节点 ID。

排序不改变节点协议、已有连线、工具可见性和端口兼容性筛选。同一个节点的多个兼容端口候选全部保留，未配置的新节点排在末尾。已有有效本机自定义分类偏好在归一化时保留。
