# 对话图片附件：接入与诊断影响

- 桌面对话统一附件入口支持图片及可读取文本；新增 PDF、DOCX、XLSX、PPTX 使用现有桌面文档提取。图片作为用户消息的媒体引用保存，主进程仅向已验证图片输入能力的模型发送当前项目的真实媒体。支持 PNG、JPEG、WebP、GIF，每张不超过 10 MB，每次最多 4 张；整个请求最多 20 张。图片不是生图参考图。
- `ChatStartInput.projectId` 为可选新增字段；无图片的既有请求保持原有行为，图片请求必须提供项目并校验归属。旧消息仍可读取；旧版本不会理解用户图片附件，升级后保存的数据不承诺在旧版执行。公开节点端口和外部操作 Schema 无变更；外部 Agent 尚不支持对话执行。技能 Agent 使用同一网关链路，不另建执行器。
- 导入复用媒体缓冲 IPC 和媒体存储，新增开始/成功/失败诊断；媒体保存失败返回受控错误，日志故障不改变结果。请求沿用模型请求诊断，不记录图片、提示词、文件名或路径。文档导入复用现有提取与诊断；扫描件无文字层不假装读取成功。
- 本机确定性夹具检查图片请求构造、视觉能力验证、跨项目拒绝、持久化重映射、导入失败和日志脱敏；不等同于真实供应商验证，也不执行收费请求。
- 外部接入保护清单原有的三个已提交文件与旧影响记录不一致。核对其差异仅为提交 c25d2fa 的节点分类由 logic 重组为 ai/data/video（registry、agentFlow、specs/index），节点端口与执行器未变；对应分类、端口、节点合规及回归测试作为本次影响复核证据。此前的 P1 IO 缓存、账本和恢复影响说明保留在历史提交及旧记录中。
