# 2026-11-06 画布组合/分组交互与视觉修正

## 背景

用户反馈：
1. 折叠图标不像"折叠/堆叠"，且鼠标悬浮出现一块背景；
2. 分组名双击重命名的编辑态很 low；
3. 折叠后标题显示「可复用」，应保留原分组名（灰色、可编辑）；
4. 堆叠错位随节点数变大，应固定为两个节点时的 20px 内插卡；
5. 组合/取消组合按钮在深色画布上太单薄，需要固定淡底；
6. 文案「打组」应统一为「组合」；
7. 视频截取/抽帧 tab 切换仍有问题。

## 一、折叠/展开图标与按钮

- `fold` / `unfold` 图标重画为"两张卡片"：折叠=两张卡错位堆叠，展开=两张卡并排；不再使用箭头。
- `.canvas-group-collapse-btn`、`.canvas-combo-btn`：
  - 保留固定的淡卡片底（rgba(18,23,31,.72)）+ 1px 发丝边，图标为灰白；
  - **去掉 hover 背景高亮**，悬浮只加深图标/描边颜色，避免"点一下冒出一块背景"。

## 二、折叠态标题

- 去掉「可复用」徽标，改为沿用 `group.meta.label`（默认「分组」）+「· N 个节点」的灰色标题；
- 折叠态标题支持**双击重命名**：与展开态共用 `commitGroupName`，写回 `group.meta.label`；
- 输入框改为卡片材质（#1b202b→#151922）、8px 圆角、22px 高、聚焦仅 1px 青色描边，无发光/蓝色；
- 新增 `canvas-combo-name-input` 静态布局，嵌在折叠标题行里。

## 三、堆叠距离

- `collapseGroup` 的成员错位从"每个成员固定 20px、随数量累计"改为
  "总错位固定 20px，成员在这段距离内均分"：`perCardStep = 20 / (N-1)`；
- 2 个节点仍是 20px；N 个节点不再越叠越宽，只往中间插卡。

## 四、组合容器与按钮底色

- 展开态分组框：浅透明改为一层接近卡片的深色底（`rgba(27,32,43,.55)`），遮挡时边界可见；
- 折叠组合外框：由几乎透明的蓝灰改为卡片同族实底渐变（`.92` 不透明）+ 柔和投影；
- 多选工具条「组合 / 取消组合」：固定淡底 + 1px 发丝边，不再是裸图标；
- 文案统一：「打组」→「组合」，「拆分分组」→「取消组合」（含 aria-label / title / QA 脚本）。

## 五、视频截取/抽帧切换

- 根因：工作台遮罩在 `pointerdown` 阶段对所有子控件调用 tldraw 的
  `stopEventPropagation`（含 preventDefault），部分浏览器的 click 被吞掉，标签切换无反应；
- 改为：只有 `event.target === mask` 时才停止冒泡并关闭；子控件 pointerdown 不再被 preventDefault；
- 移除标签按钮上多余的 pointerdown 拦截；关闭按钮保留 pointerdownCapture 关闭，避免下拉层吞点击。
