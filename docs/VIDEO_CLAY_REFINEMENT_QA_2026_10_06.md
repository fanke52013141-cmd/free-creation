# 白模第二轮：降低法线描边噪声

2026-10-06。接续第一轮 v2，不新增模型、端口或配置字段；v1 浮雕算法不变。

## 改动与实际观感

同一 Small 深度仍存在阶梯边缘，一像素差分将其放大为朝向尖峰，照明后出现细黑线。本轮在计算法线后使用两层、随尺寸缩放的朝向邻域平均。按深度差衰减权重，差值达到 0.06 拒绝融合；重新归一化为单位法线。法线只由深度生成，不读取原片颜色或纹理。

同一人物样片、同一份标准档深度、同一时间稳定及光照参数，24 帧/12 fps。对比左右为原片、第一轮、第二轮，保留整段视频及第 0/50%/90% 截图。检查发现衣服、手臂、桌面线状阴影变柔和，大面光照更连续。轮廓仍存在少量断层，未恢复人脸与头发结构，细小几何也可能被柔化。不能称为完整三维白模或所有视频均已达标。

同源缓存深度渲染实测：第一轮 2.756 秒、第二轮 4.236 秒（24 帧）。新增处理约 1.48 秒；不含推理、启动与编码。不是免费性能提升，长片仍需另测。

## 验证与复现

- Python 11 项通过，其中新增已知曲面上的朝向噪声误差减少、单位法线/大面曲率保留，以及前景/背景朝向不同的硬断层完全不混合。
- 真实 Electron IPC：活跃与排队取消、解释器树无残留、后续队列释放；v1、v2 输出完整解码，24 帧/2 秒；v2 音轨开/关符合设置，临时 job 目录为零。音轨夹具显式添加正弦音，原片无音轨。
- 全量 `npm run verify` 与最终 lint：证据在 `artifacts/clay-refinement-2026-10-06/verify.log`、`lint-final.log`。包括类型、1514 项 JS 测试、2 项模型测试、日志门禁、28 节点 UI 门禁及生产构建。
- 对比脚本：`scripts/compare-clay-refinement.py --source <同源样片> --depth <对应缓存.npy> --previous-renderer <上一版clay_renderer.py> --output <独立产物目录>`。使用已安装本地 Python 推理环境与 FFmpeg，不调用收费模型，不下载权重。
- `CLAY_RUNTIME_OUTPUT` 可指定 IPC 验收的独立产物目录，其中需先放入 `source-sample.mp4`，避免覆盖上一轮证据。

## 五轴复核与日志影响

正确性：断层拒绝只作用于新法线平滑，v1 保持原路径；光照、配置和输出语义不变。合成测试与实际整段解码分别证明几何边界与输出完整性，视觉改进限于所测样片。

可读性：单一纯函数，说明差分噪声来源与阈值，不引入 UI 参数和迁移。

架构：只在 v2 几何着色内部调用，复用执行器、IPC、编码及资产保存。

安全：缓存读取禁止 pickle；用户原媒体只读，不写用户项目，不新增网络、凭据或原帧日志。

性能：邻域数量固定为八个，不保留帧历史或增加推理显存；接受测得的 CPU 渲染开销。极长片内存仍受原批量深度链路约束。

日志：复用第一轮固定渲染版本与独立结果 trace、公共开始/失败/取消/终态，不记录逐帧平均；worker 阶段 JSON 未单独持久化的边界未改变。
