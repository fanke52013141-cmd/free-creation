# 对话生图上下文与 2K 影响记录

- 桌面显式生图将当前会话的文字摘要、文本消息和当前绘图要求传给既有图片生成网关；不调用其他会话，不新增图片输入或输出端口。总提示词上限为 32000 字符，超限优先保留近期历史，本次要求本身超限时不提交。
- 2K 仅在图片模型能力表允许时提交；默认 1K、最低质量、每次最多一张、无自动重试保持不变。旧项目的 1K/4K 配置仍可读取，新增 2K 配置在旧版软件中会回退为 1K。
- 外部 Agent 的 chat 节点执行仍未开放；操作目录、外部 Schema、媒体保存与占用协议均未变。未新增外部执行器或接入入口。
- 日志复用节点生命周期及图片网关请求/落盘事件，失败事件增加提示词私有值脱敏，不记录对话内容。对话界面改版属于展示层，不新增日志事件。
- 定向测试覆盖当前会话隔离、历史长度、2K 参数、失败和取消；浏览器夹具验证发送、预览、下载和保存恢复，不代表真实收费供应商验收。
- 外部接入门禁现有哈希记录与 `registry.tsx`、`agentFlow.tsx`、`index.tsx` 等本次未修改文件已不一致；不把未审查的既有变化一并刷新为已确认。完整验证结果以本次实际执行为准。
