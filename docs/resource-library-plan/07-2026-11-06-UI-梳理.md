# 资源库 2026-11-06 UI 梳理

本文件记录本轮按用户反馈对资源库做的界面与语义梳理。定位讨论（固定资产 / 组合资产边界）另行确认，本文只记录已落地的交互裁决。

## 1. 页面骨架

- 顶栏与首页、画布一致：浏览器 44px / 桌面标题栏 46px，背景 `#0d0d0d`；桌面版右侧为原生最小化/最大化/关闭按钮预留 138px，并加 1px 分隔线与拖拽区。顶栏 `z-index: var(--z-topbar)` 必须高于窗口拖拽层，否则桌面版会被遮住（本轮实测问题）。
- **不再显示左侧“返回”按钮与竖线**：标题「◇ 资源库」直接靠左；右侧依次为搜索框、导出图标、新建分类、编辑分类、主按钮「新建资源」，**最右侧保留固定返回图标**（`aria-label="返回项目列表"`），确保任何情况下都能回项目列表。导入入口按用户要求暂不放在资源库顶栏。
- 分类行的「共 N 项」计数已移除；分类标签行只保留分类切换。

## 2. 卡片规格

- 封面固定 **16:9**（`aspect-ratio: 16/9`），压缩卡片总高度；有图片时显示图片：优先分类「封面内容」槽位，其次持久化封面，最后回退到最新版本的第一张图片。
- 无图片时使用**等距立体魔方**默认封面（Stitch 参考稿 `qa/stitch-cube/cube.png` 落地为内联 SVG）：30° 真等距、三面明暗、3×3 细线分格、青灰单色，不使用渐变/光晕。
- 卡片材质对齐画布节点：深蓝黑渐变、1px 发丝描边、14px 圆角、轻阴影；悬停上抬 3px + 淡青色描边 + 柔和投影，封面底部有一层到卡面的渐隐过渡。
- 版本显示统一为 **1.0 / 2.0 / 3.0**（不再用 v1/v3），标题 + 版本胶囊 + 单行说明。

## 3. 分类

- 分类标签不再各自携带编辑按钮；统一收进筛选行右侧「管理分类」菜单（列出全部分类可进入编辑，并提供新建分类）。
- 分类选中态为文字变青 + 2px 下划线。
- 「已归档」入口固定在筛选行右侧，与普通分类区分颜色。

## 4. 删除与版本语义（原「基于此版本编辑 / 归档」的梳理）

| 旧文案 | 现文案 | 行为 |
| --- | --- | --- |
| 基于此版本编辑（最新） | 编辑资源 | 打开资源表单，保存后发布新的当前版本 |
| 基于此版本编辑（历史） | 以 vN 为基础新建版本 | 复制该历史版本内容为草稿，保存后成为新的最新版本；历史版本本身不变 |
| 归档 / 恢复资源 | 删除资源 | 二次确认后彻底删除（含全部版本、组件与引用文件），不可恢复 |

- **不做归档**：用户裁决"删掉就没了"；资源列表不展示归档状态，也不再提供「已归档」入口。
- 删除同时清理组件、版本、蓝图、标签、集合/目录归属与使用记录，并回收不再被引用的 blob 文件。
- 详情抽屉底部：左侧「删除资源」（危险色，二次确认），右侧主操作「编辑资源 / 以 vN 为基础新建版本」。

## 5. 详情抽屉

- 宽 420px，右侧展开，遮罩从顶栏下方开始（不遮挡系统按钮）。
- 头部 48px 固定、正文滚动、底部动作区固定；头部标题栏下方为类型胶囊 + 版本胶囊、资源标题、说明与标签（不显示更新时间/组件数等多余元信息）。
- 资源内容按组件分组：每行显示「名称 + 类型（图片/文本/音频…）」+ 真实预览，不再有勾选框与「选择要复用的组件」提示。
- 版本记录只保留 `vN + 日期` 与修改说明，不显示「最新/查看中」标签与迭代次数；「比较两个版本」保留为折叠工具。
- 已移除「放入项目」区块：项目侧资产库已提供统一入口，详情里不再重复项目选择与配方预览提示。

## 6. 表单弹窗

- 新建/编辑资源：去掉英文 `RESOURCE` 小标题、「可直接组合图片、音频、视频…」与其它重复提示；编辑已有资源时标题为「编辑资源」、主按钮为「保存为新版本」，清晰表达"编辑会生成新版本"；组件类型显示中文名（图片/文本/音频/视频/文件/结构/提示词配方）。
- 新建分类：只保留两组内容——「基本信息」（分类名称、分类说明）与「包含的节点」（每个槽位：内容名称、映射到节点、必填、允许多项、上移/移除，可添加多个槽位）。
  - 已移除「展示样式 / 封面内容 / 加入画布后的排列 / 节点名称模板 / 展开预览」这类蓝图设置：卡片统一使用 16:9 图片卡片；封面自动取“第一张图片，没有图片则用魔方默认封面”；放进画布默认按网格排列；节点名称按「内容名称 + 序号」自动生成，不再要求用户手写模板。
- 分类的「新建分类」与「编辑分类」都收进顶栏；点击编辑分类弹出分类列表菜单。

## 7. 未覆盖边界

- 浅色主题、640px 以下窄屏、真实大文件缩略图与超长文案未逐项截图。
- 硬删除无单元测试覆盖（仅类型检查与构建通过）；删除会清理无引用 blob 文件，文件删除失败不改变数据库删除结果。
- 资源库定位（固定资产/组合资产的工作流语义）仍需产品确认，本文不改变既有数据与执行契约。
