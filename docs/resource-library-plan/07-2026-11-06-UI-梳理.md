# 资源库 2026-11-06 UI 梳理

本文件记录本轮按用户反馈对资源库做的界面与语义梳理。定位讨论（固定资产 / 组合资产边界）另行确认，本文只记录已落地的交互裁决。

## 1. 页面骨架

- 顶栏与首页、画布一致：浏览器 44px / 桌面标题栏 46px，背景 `#0d0d0d`；桌面版右侧为原生最小化/最大化/关闭按钮预留 138px，并加 1px 分隔线与拖拽区。
- 左侧固定「← 返回」与「◇ 资源库」；右侧依次为搜索框、图标工具组（导入资产包 / 导出资产包 / 新建分类）、主按钮「新建资源」。
- 除「新建资源」保留品牌色主按钮外，导入、导出、新建分类均为纯图标按钮（带 `title`/`aria-label`）。
- 页面顶部与内容区统一纯黑 `#0d0d0d`，分类筛选行与内容之间只保留 1px 极淡分隔线。

## 2. 卡片规格

- 封面固定 **16:9**（`aspect-ratio: 16/9`），压缩卡片总高度；有图片时显示图片：优先分类「封面内容」槽位，其次持久化封面，最后回退到最新版本的第一张图片。
- 正文只保留三样：**标题**（13px/600）、**版本徽标**（`v3` 胶囊）、**单行说明**（超出省略）。
- 删除「N 个组件」与标签行（用户裁决：不关心组件数量）。
- 选中态/悬停态只做轻量反馈：悬停上抬 2px + 青色描边（`rgba(66,185,245,.35)`），不加发光。

## 3. 分类

- 分类标签不再各自携带编辑按钮；统一收进筛选行右侧「管理分类」菜单（列出全部分类可进入编辑，并提供新建分类）。
- 分类选中态为文字变青 + 2px 下划线。
- 「已归档」入口固定在筛选行右侧，与普通分类区分颜色。

## 4. 归档与版本语义（原「基于此版本编辑 / 归档」的梳理）

| 旧文案 | 现文案 | 行为 |
| --- | --- | --- |
| 基于此版本编辑 | 编辑资源（最新版本） | 打开资源表单，保存后发布新的当前版本 |
| 基于此版本编辑（历史版本） | 以 vN 为基础新建版本 | 复制该历史版本内容为草稿，保存后成为新的最新版本；历史版本本身不变 |
| 归档 | 移入归档 | 不删除内容；默认从资源列表、搜索与选择器隐藏 |
| 恢复资源 | 恢复资源 | 在「已归档」筛选中恢复，回到资源列表 |

- 归档**不是删除**，不会丢失内容或历史版本；资源库里没有"不可恢复删除"入口。
- 详情抽屉底部：左侧「移入归档 / 恢复资源」+ 一句说明，右侧主操作「编辑资源 / 以 vN 为基础新建版本」。

## 5. 详情抽屉

- 宽 420px，右侧展开，遮罩从顶栏下方开始（不遮挡系统按钮）。
- 头部 48px 固定、正文滚动、底部动作区固定；头部标题栏下方为类型胶囊 + 版本胶囊（+ 已归档标签）、资源标题、「更新于日期 · N 个组件」、说明与标签。
- 资源内容按组件分组（保留真实缩略图/音频/文本预览，图片预览最高 180px），版本时间线保留「比较两个版本」。
- 「放入项目」保留项目选择与「打开画布并创建节点」。

## 6. 表单弹窗

- 新建/编辑资源：去掉英文 `RESOURCE` 小标题与「可直接组合图片、音频、视频…」提示；底部按钮统一右对齐（取消在左、保存资源/发布新版本在右）。
- 新建分类：720px 模态，三组编号区块（基本信息 / 展示与封面 / 包含的节点），节点槽位紧凑化，移除/上移改为槽位右上角图标按钮，底部保存区固定且右对齐。

## 7. 未覆盖边界

- 浅色主题、640px 以下窄屏、真实大文件缩略图与超长文案未逐项截图。
- 归档分页：当前为按页取回后客户端过滤，跨页归档数量极大时可能一次显示不满 48 条。
- 资源库定位（固定资产/组合资产的工作流语义）仍需产品确认，本文不改变既有数据与执行契约。
