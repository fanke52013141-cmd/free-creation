# 当前实现、使用方式与边界

> 新提出的“用户可配置资源分类 = 展示样式 + 节点蓝图”见[修订提案](05-资源分类与节点蓝图-提案.md)。当前版本仍使用固定 `formPreset` 和逐组件加入画布，尚不支持整份资源按蓝图实例化为一组节点。

更新日期：2026-09-26。本文记录三期方案对应的当前代码实现，不替代 `01` 产品交互和 `02` 总体分期方案。

## 一期：项目、工作台与可复用资源

- 首页“新建项目”打开节点配置弹窗。可按节点类别搜索、整类勾选，也可从通用/图像/视频/音频/全部预设开始选择。
- 工作台左侧节点栏和双击画布创建菜单按项目配置过滤；项目菜单可再次打开“工作台节点设置”。既有项目没有配置时继续显示全部可用节点。
- 首页项目卡片有“复制项目”操作。复制包括项目 JSON、画布快照、项目素材、工作台配置和资源库使用来源；复制后重新映射项目/节点/画布/媒体 ID，副本中的运行任务标记为取消。媒体分阶段落入临时目录，数据库提交后才会显示为项目。
- 首页“资源库”支持图片、提示词、人物、场景、风格和自定义资源。资源使用通用组件结构，图片、文字、音频、视频和文件可以组合保存。资源版本不可变，支持从历史内容派生新版本、按用途/文本/文件哈希比较版本、添加标签与收藏集、归档和恢复。
- 项目素材面板提供“项目素材 / 资源库”切换。可以在资源库搜索组件并加入项目；文件组件复制到当前项目，提示词/文本可以填变量预览后创建文本节点。
- 项目素材卡片悬停时提供收藏入口。当前图片、视频（包括深度/白模转换结果）、音频或文件会被复制进全局库，源项目保留原文件。

## 二期：组合、配方和风格展板

- 人物/场景/风格基于同一组件编辑器，而不是分别建三套数据结构；可组合多张图、描述、提示词、声音样本和其他文件。
- 提示词配方保存 `{{变量名}}` 模板、变量定义、参考组件用途和模型参数 JSON。资源详情中可填写变量并预览；从项目资源库选择器使用配方时，将填好的预览文本作为文本节点加入画布。
- 展板支持固定具体资源版本、摆放卡片、记录观察说明、拖动调整与移除。所固定版本落后于当前版本时展示“已有新版本”提示。
- `.canvaslib` 自包含包导入/导出资源、历史版本、文件、标签、收藏集与展板位置/说明；导入时重新映射 ID、校验文件大小与哈希，并拒绝重复导入同一个包。

## 三期：视频深度 / 白模与资源库联动

- `video-depth` 和 `video-clay` 节点、Video Depth Anything Small 本地推理及基础白模着色已存在于工程。此次没有再造一套视频节点，而是让项目素材面板可以把转换结果直接收藏进资源库，再从其他项目搜索并作为视频素材加入画布。
- 两节点无需 ComfyUI。新电脑仍须按[换机安装说明](../VIDEO_CONVERSION_SETUP.md)准备 Windows x64、NVIDIA CUDA 驱动、系统可发现的 Python 3.12 和 FFmpeg/FFprobe；应用在线安装隔离依赖并下载模型。模型权重和推理环境不随 Git 项目克隆。离线安装包尚未实现。
- 白模是深度估计驱动的二维浮雕/着色结果，不是三维重建；真实效果边界和可调参数见换机说明。Windows RTX 5080 的样片已验证，不代表其他显卡、Linux 或长视频已完成验收。

## 数据归属与限制

- 资源库是当前机器上的全局本地库，位于应用数据目录，与安装目录和项目目录分开。它不依赖登录、云端服务或 ComfyUI；迁移机器时使用 `.canvaslib` 资源包。
- 单个库文件目前最多 128 MB；一个资源包最多 512 MB。视频收藏超过单文件上限时需要先裁剪/缩小，或者后续再实现大文件流式存储。
- 收集采取“库持有独立副本”策略。修改库资源不会自动改写已复制到项目中的内容；项目记录资源版本与已物化媒体来源。
- 人物/场景/风格目前是可组合的通用组件表单，尚未做针对专业用户的专用表单向导。收藏集暂不支持重命名/删除；归档保留历史数据，永久清理与 blob 垃圾回收尚未实现。
- 配方中的模型参数与参考用途会被保存、展示并打包，但当前不会自动覆写模型节点参数，也不会触发模型运行。用户确认变量后，配方按预览文本进入普通文本节点。
- 项目复制当前为完整复制，没有“仅结构”模式、进度条或取消操作；它会校验每个源项目媒体文件存在且大小一致，缺失时整次失败，不显示半成品。
- 资源库不自动扫描并导入旧项目的全部生成历史；用户显式点击素材卡片的收藏入口后才保存。
