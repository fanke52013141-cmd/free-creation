# 项目工作台、全局资源库与视频转换优化方案

版本：v1.1 · 日期：2026-09-26 · 状态：分期方案 + 当前实现记录

> 视频转换更新：请以 [独立双节点最终方案](../VIDEO_CONVERSION_FINAL_PLAN.md) 为准。最终不依赖 ComfyUI，深度节点与白模节点均直接接收原视频；本目录的视频建议保留为历史参考。

本方案聚焦四项当前需求：项目复制、创建项目时选择可见节点、全局资源积累与复用、视频深度/白模转换。Agent 开发独立保留在既有方案中，不是本方案前置条件。

## 建议决策

- 全局入口命名“资源库”，现有项目资产面板命名“项目素材”，避免两个“资产”入口含义混淆。
- 资源以独立的业务对象保存，可含图片、提示词、音频及其他组件；人物、场景和风格采用预设表单。
- 资源、收藏集、展板和工作流模板分别承担内容、组织、浏览和执行职责。
- 资源版本不可变，项目使用固定版本；编辑库内容不自动改变已使用的项目。
- 首版采用“全局持有副本，使用时落为项目素材”的生命周期策略，保证删除源项目后资源可用。
- 所有节点都可打开资源搜索；实际插入按输入端口、内容类型和基数过滤，不能把任意资源硬塞到任意节点。
- 项目复制采用一致性快照和引用重映射；复制之后默认不运行任何任务。
- 视频深度优先验证 Video Depth Anything Small；ComfyUI 是可选执行后端。
- 将“深度控制视频”“白模质感视频”“可编辑三维场景”明确区分。先交付深度，再验证近似白模效果。

## 方案制定时的代码基线

| 项目 | 当前情况 |
|---|---|
| 项目复制 | ProjectListPage 当前有导出、重命名、删除，没有项目复制入口；未检索到对应 clone/duplicate project 实现 |
| 项目创建 | 首页采用行内名称输入；画布项目菜单可直接创建“未命名项目”，需要统一弹窗 |
| 节点选择 | palette-preferences 是本机分类顺序/名称偏好；ProjectFile 当前没有项目级可见节点集合 |
| 资产面板 | AssetsPanel 通过 projectId 加载素材；media.repo 按项目媒体路径查询，不是全局知识/资源库 |
| 素材迁移 | 已有项目打包导入导出、媒体引用重映射，可抽取复用，不能仅新增按钮就认为复制完整 |
| 白模能力 | 导演台已有本地空间布置和白模预演视频导出；当前需求是另一个方向：导入视频反推深度/白模 |

## 三期建议

| 期次 | 结果 |
|---|---|
| 第一期 | 项目复制、节点配置弹窗、图片/提示词资源库、基础版本与跨项目调用 |
| 第二期 | 人物/场景/风格组合资源、声音组件、风格展板、提示词迭代与配方、资源迁移 |
| 第三期 | 深度视频节点、可替换执行后端、白模近似效果实验及通过验收后的发布 |

分期实施状态与实际限制以[当前实现说明](04-当前实现与边界.md)为准。视频转换已有单独实现与换机依赖文档；本轮把转换产物接入全局资源库。

视频技术试验可以在资源库开发期间提前开展，不必等待第二期结束；正式集成遵守独立节点协议。

## 交付说明

上述“只新增方案文档”描述的是 v1.0 方案编写时的状态，不代表当前工作区。实施过程与真实能力范围见 v1.1 当前实现说明。

本文暂将“白膜”理解为保留构图与运动的白色无纹理模型效果，产品文案使用“白模”。深度视频作为独立用途同时规划，最终以用户确认的目标样片细化。
