## 并行与组合链路

已由代码测试覆盖的组合包括：

1. 文本 → 对话 / AI 处理 / 生图 / 视频 / 配音。
2. 图片 → 裁剪 / 拆分 / 修改 / 生图；拆分列表 → 循环。
3. 视频 → 取帧 / 截取 / 提取音频；提取音频 → TTS 参考语音；取帧结果 → 图片处理。
4. 音频 / TTS → TTS 参考语音；音频 → 人声分离。
5. JSON / 结构数据 → 生图、视频、代码、循环、分镜板。
6. 分镜板 → 3D 预演台；预演视频 → 视频运动参考。
7. 多输入端口的 cardinality、必填输入、Schema 不匹配和非法媒体类型均有拒绝测试。

这些是执行器、契约和 Headless 层面的并行验证。浏览器端已完成节点批量创建和布局审查，但当前 CUA API 没有鼠标拖拽/滚轮接口，因此真实拖线、Ctrl+滚轮和多分支鼠标操作仍需桌面验收。

## 当前问题与风险

### P0：已修复浏览器验收入口

之前直接运行根目录 Vite 会返回 404，且不会加载 Electron 的 renderer alias。已新增 `vite.browser.config.ts` 和 `npm run dev:browser`，明确使用 `src/renderer` 作为 root 并补齐 alias；页面现在可以加载并完成核心 UI 实测。

### P1：浏览器演示模式不执行真实媒体能力

`browserMock.ts` 明确将媒体导入、裁剪、视频取帧/截取/提音、图片生成/修改设为 MOCK 失败，并将 ffmpeg/ffprobe/人声分离能力报告为不可用。这是演示限制，不代表 Electron 主进程实现失败，但必须在桌面应用中验收。

### P1：JSON 节点两种输入入口的执行语义不一致

关系实测发现：在 JSON 节点正文内直接编辑出“JSON 有效”后，点击节点运行曾返回 `JSON 输入格式无效`；同一份数据从“输入输出”详情页的“未连线测试”入口注入，则测试成功并能作为 `out-json` 传给结构数据节点。建议统一这两条入口的持久化字段与执行器读取字段，避免用户看到“JSON 有效”却运行失败。

### P2：待清理的工程质量项

- 131 个 Prettier 警告集中在既有文件，当前不影响构建或测试，但建议单独格式化提交。
- 构建有 `bodies/shared.tsx` 动态导入与静态导入并存的 Vite 提示，不影响产物，但可整理模块边界。
- `.conn-*` 与 `.data-edge-*` 两套连线样式仍同时存在；当前业务线由 `DataEdgeLayer` 使用 `.data-edge-*` 绘制，旧样式可在视觉验收后清理，避免未来误改。
- 运行按钮浮动在 `top: -34px`，状态徽章最大宽度 116px；当前 23 节点浏览器验收未发现重叠，但长标题或极窄节点仍建议在桌面窗口复核。
