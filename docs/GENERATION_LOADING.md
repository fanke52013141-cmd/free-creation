# 加载动效与预计进度

启动页、画布节点、聊天侧栏、导演工作台、项目列表、资源详情、运行诊断时间线和本机视频推理设置共用暗底蓝色点阵。侧栏中的资源详情和时间线使用紧凑布局。系统开启减少动态效果时，点阵保持静止。

生图使用选定渠道的成功耗时记录，优先匹配同一模型。其他支持耗时采样的节点按任务类型、渠道和模型估算，并结合输入规模调整。新渠道先使用初始估算。运行时显示「预计进度」，达到 99% 后等待任务终态。

## 日志与验证

本次调整展示和估算的样本筛选，复用现有执行日志、成功耗时存储和失败诊断。没有新增采集字段。

浏览器模拟覆盖节点库 32 种可执行节点的运行态和遮罩收起。生图用例另验证 99% 上限及减少动态效果。耗时测试覆盖历史存取、渠道隔离及初始估算。独立浏览器验收使用 node scripts/test-browser-generation-loading.cjs，需要启动浏览器开发服务器。脚本还通过应用执行器运行生图，并验证成功后回写所选渠道与模型的耗时。浏览器模拟未发起真实供应商请求。
