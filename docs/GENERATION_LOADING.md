# 加载动效与预计进度

启动页、画布节点、聊天侧栏、导演工作台、项目列表、资源详情、运行诊断时间线和本机视频推理设置共用同一「星辰加载场」。暗青底 `#081113` 上有近大远小的青白星尘。**加载开始后 ≤600ms 内四组星星按中心向外错峰全部淡入**。星星从出现时就开始漂浮，有预计进度时速度随进度平滑上升，在 99% 封顶并等待任务结束。闪烁节奏独立，标题后的三个点从左到右依次亮起。侧栏中的资源详情和时间线使用紧凑布局（约 28–36 颗星），较大容器按面积绘制。星尘使用 Canvas 2D，DPR 上限为 2，容器尺寸变化由 ResizeObserver 处理。

性能与无障碍：页面隐藏（`document.hidden`）或加载场滚出可视区（IntersectionObserver）时暂停 `requestAnimationFrame`；系统开启减少动态效果（`prefers-reduced-motion: reduce`）时只绘制一帧静态星空，星星仍然全部可见，没有任何动画。加载场通过 `.generation-loading-field` 上的 `data-motion` / `data-stars` / `data-star-visible` / `data-reveal` 暴露运行状态，供浏览器验收脚本断言。

生图使用选定渠道的成功耗时记录，优先匹配同一模型。其他支持耗时采样的节点按任务类型、渠道和模型估算，并结合输入规模调整。新渠道先使用初始估算。运行时显示「预计进度」，达到 99% 后等待任务终态。

## 日志与验证

本次调整只改展示层动效与样式，不涉及节点执行、模型请求、异步任务、文件或数据库路径，日志覆盖无变化，不新增采集字段。

浏览器模拟覆盖节点库 32 种可执行节点的运行态和遮罩收起，并断言画布绘制出星点、星星在 ≤600ms 内全部出现。生图用例采样实际绘制的星点位置，对比刚开始与 99% 时的移动速度，并验证三个点逐个亮起。减少动态效果时，星空和三个点均静态显示。独立验收先启动 `npm run dev:browser -- --port 5196`，再运行 `node scripts/test-browser-generation-loading.cjs`。脚本还通过模拟供应商验证生图成功后回写所选渠道与模型的耗时。浅色主题与真实供应商生成的观感未纳入本次自动化。
