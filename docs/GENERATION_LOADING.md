# 加载动效与预计进度

启动页、画布节点、聊天侧栏、导演工作台、项目列表、资源详情、运行诊断时间线和本机视频推理设置共用同一「星辰加载场」：暗青底 `#081113` 上漂浮 Canvas 2D 星尘光点（主题青 `#3cdde3`、亮青 `#86eef3`、暖白核心），近大远小、缓慢正弦漂浮与呼吸闪烁。与早期暗底蓝色点阵相比，星星不再由进度逐颗激活：**加载开始后 ≤600ms 内四组星星按中心向外错峰全部淡入**，之后只做缓慢漂浮与闪烁；进度仅表现为轻微亮度抬升和一条极淡的青绿扫光，不决定星星是否出现。侧栏中的资源详情和时间线使用紧凑布局（星数约 28-36）；节点执行遮罩等较大容器按面积约 80-100 颗。星尘由 Canvas 2D 绘制，无 WebGL 依赖；DPR 上限 2，尺寸变化由 ResizeObserver 重新布局。

性能与无障碍：页面隐藏（`document.hidden`）或加载场滚出可视区（IntersectionObserver）时暂停 `requestAnimationFrame`；系统开启减少动态效果（`prefers-reduced-motion: reduce`）时只绘制一帧静态星空，星星仍然全部可见，没有任何动画。加载场通过 `.generation-loading-field` 上的 `data-motion` / `data-stars` / `data-star-visible` / `data-reveal` 暴露运行状态，供浏览器验收脚本断言。

生图使用选定渠道的成功耗时记录，优先匹配同一模型。其他支持耗时采样的节点按任务类型、渠道和模型估算，并结合输入规模调整。新渠道先使用初始估算。运行时显示「预计进度」，达到 99% 后等待任务终态。

## 日志与验证

本次调整只改展示层动效与样式，不涉及节点执行、模型请求、异步任务、文件或数据库路径，日志覆盖无变化，不新增采集字段。

浏览器模拟覆盖节点库 32 种可执行节点的运行态和遮罩收起，并断言：星辰画布存在且尺寸大于 0、星数大于 0、星星在 ≤600ms 内全部出现（`data-reveal` 由组件记录的挂载与完成时间计算）、减少动态效果下 `data-motion="off"` 且画布仍绘制出静态星空。生图用例另验证 99% 上限。耗时测试覆盖历史存取、渠道隔离及初始估算。独立浏览器验收使用 node scripts/test-browser-generation-loading.cjs，需要启动浏览器开发服务器（`npm run dev:browser`，默认 `http://127.0.0.1:5173`）。脚本还通过应用执行器运行生图，并验证成功后回写所选渠道与模型的耗时。浏览器模拟未发起真实供应商请求；浅色主题与真实模型生成过程中的观感未在本次自动化中覆盖。
