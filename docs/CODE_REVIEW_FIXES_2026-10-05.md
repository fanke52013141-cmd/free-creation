## 对报告结论的校正

- `_` 出现在约 17% 项目 ID 中不等于约 17% 必定发生跨项目读取；还需要存在能匹配的邻居。资源库捕获此前还带 startsWith 归属检查，克隆也有后续校验，因此报告所述所有影响并非都已实证发生。5 处模糊查询仍是实际缺陷，已统一消除。
- tldraw 内部 Editor/store 销毁会处理部分资源，原报告没有完整证明跨项目快照写错已经发生。本轮补齐显式清理并实测生命周期，不以推测当事故事实。
- runNodeTest 当前在隔离副本上执行，不会直接改原节点结果；并发仍会产生真实请求，因此已增加互斥。
- 原 readiness 仅在 modelAvailable === false 时阻断，undefined 不会自动让全画布禁用。内容稳定与 IPC 去重解决的是确实存在的重复解析和状态失效成本。
- 固定当前时钟不禁止显式构造输入日期，Date.parse/Date.UTC 并不是绕过“当前时间”；仍保留显式日期能力。UTC 帮助函数修正跨时区格式，原生显式日期解析仍遵循 JS 语义，不声称所有 Date API 都与时区无关。
- electron-builder --config.directories.output=value 是有效写法，独立实际打包已证明；不按报告 P1-2 改成不存在的命令修复。
- React 渲染代码由 Vite 打入浏览器 bundle，不能仅按 import 次数推断必须移入生产 dependencies。本轮不迁移 React；@types/three 的 dev 分类建议合理，但不影响运行，暂保留现有依赖/锁文件，避免扩大 peer metadata 改动。
- docs 是工程规范，不应加入 .gitignore；旧人工确认基线保留，新的可再生产物默认忽略。
