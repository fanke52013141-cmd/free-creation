# Handoff：画布节点与工作流交互收口（2026-09-23）

基线：`53c738e`（`main` / `origin/main`）。

## 本次代码范围

- **节点外观与画布交互**：空闲端口只显示节点主色，连线/拖线候选显示数据类型色；端口命中区放大；连线不再播放装饰性流动动画；选择框几何改为只包节点本体；滚轮优先滚动指针下可滚动的节点内容，到边界后交还画布，Ctrl/Command + 滚轮继续缩放。
- **AI 处理与对话节点**：AI 处理配置移入标准详情「设置」，输出通过声明的 `out-text`、`out-markdown`、`out-json` 端口交给显式连接的下游节点；对话节点补齐概览、I/O 和设置详情。聊天历史以会话形式保存在节点数据中，支持新建/切换、重生成、编辑并截断后续消息。
- **图像生成**：支持 1–9 张输出及网格排列；画幅优先级为 9:16、16:9、1:1、21:9、4:3、3:4；本地按供应商与模型记录成功耗时，生成进度按估时增长，超时停在 99%。耗时样本不保存提示词、API Key 或媒体内容。
- **工作台和节点布局**：裁剪预览铺满可用区域并保持裁剪坐标映射；P 图、抽帧、视频截取工作台可关闭后交由统一节点运行器执行；由节点创建的后继节点优先右侧对齐，冲突时向下找空位。
- **覆盖层与主题**：对话、节点详情及相关弹窗支持关闭按钮/点击遮罩关闭；移除浅色主题切换并固定深色；移除 tldraw 聚焦画布时出现在顶栏边缘的整容器高亮线。
