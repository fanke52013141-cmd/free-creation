# AI 对话生图规范

## 使用与默认值

AI 对话工作区支持生成、展示、预览及下载图片。发送方式选择“生图”，输入图片描述后发送；也可以在普通对话中明确要求生成图片，由支持工具调用的文本模型调用内置生图技能。显式生图不依赖文本模型的工具调用能力。

对话设置中可以启用或关闭生图技能，选择已配置且验证过的图片模型。默认分辨率为 **1K**，可以选择 **2K** 或 **4K**；支持质量参数的模型使用最低档 **low**，即梦 CLI 使用模型默认质量。即梦 5.0 需显式选择 2K 或 4K，不自动把 1K 升档。每次发送最多提交一次图片生成请求，只生成一张图片。模型不支持所选分辨率或最低质量时明确报错，不暗中改用其他模型或分辨率。失败不自动重新提交付费请求。

显式生图将当前会话摘要、已有文本消息及本次要求组合为文字提示词，最多 32000 字符；超长时优先保留近期对话和本次要求。本次要求本身超限则拒绝提交。其他会话和历史图片二进制不会被带入；该模式仍是文生图，不提供图片编辑。

对话模式的统一附件入口支持 PNG、JPEG、WebP、GIF 图片，每次最多四张、每张不超过 10 MB；图片先存入当前项目并作为用户消息的附件保存，重新打开和项目导入使用既有媒体重映射。图片只提交给模型目录中已启用、声明并验证过图片输入能力的文本模型；主进程再次核验所属项目、类型和大小，失败时不发出模型请求。文字附件仍作为上下文；桌面版可提取有文字层的 PDF、DOCX、XLSX、PPTX 文档。其他格式和无法提取文字的文件明确提示，不假装已被模型读取。生图模式不支持图片附件作为参考图，应先在对话模式中分析。

## 展示、保存和下载

生成结果保存为当前项目的媒体资产，助手消息只保存媒体 ID、项目相对路径、名称及 MIME。对话内显示实际图片，点击图片或“预览”打开大图；Escape 先关闭预览，对话继续保留。下载按钮调用已有媒体导出功能，让用户选择保存目录，并避免覆盖同名文件；取消目录选择不报错。

历史会话、项目保存、重新打开及项目导入导出应保留附件。项目导入使用既有媒体 ID / 路径重映射。历史压缩保留含图片的助手消息，文本请求使用摘要和近期上下文，避免把图片二进制送进文本模型。

对话节点的输出仍是最后一条助手回复的 **TXT 文本**。图片附件显示在对话中，并作为媒体资产保存；不新增隐含图片输出端口或画布节点。当前技能仅支持文字生成图片，图片编辑、任意外部技能导入及脚本执行不属于本次功能。

## 框架与边界

现有对话执行链使用 AI SDK `streamText`，无需替换为 LangChain Agent。内置规则文件为 `resources/skills/image-generation/SKILL.md`；主进程加载规则、注册 `generate_image` 工具，工具复用已有图片网关、供应商凭据、下载及落盘能力。模型只提供提示词，项目、供应商、模型、分辨率及质量由应用控制。

普通对话自动调用要求文本供应商支持工具调用；显式“生图”作为独立入口。自动调用最多三步文本交互，图片提交次数仍限制为一次。关闭技能后不向文本模型提供生图工具。

取消只能停止本地等待，远端已经接受的付费请求不保证停止。显式生图收到成功结果后会先保存图片，再处理本地取消；自动工具调用若在结果返回前取消，对话可能停止接收附件，已落盘图片仍可在项目资产中找到。不得声称取消可以退费，也不得自动补发请求。

## 诊断

自动调用记录技能开始、完成或失败，复用图片请求及媒体落盘诊断；显式生图复用节点执行阶段及图片网关诊断。媒体导出记录开始、完成、失败或取消，只记录项目、数量及状态。日志不得包含提示词、回复正文、凭据、图片内容或用户下载目录。
