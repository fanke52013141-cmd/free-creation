# 节点回归表（R0 / WP5）

> 版本基线：v0.4.0 之后 main（R0 完成时点）
> 固定底稿：内置示例项目（`resources/demo/canvas-studio-demo.canvasbundle`，首页「打开示例项目」导入）
> 用途：发布前人工回归的唯一底稿。每次发布全表过一遍并留档（§5）。

## 1. 执行前准备

1. `pnpm install && pnpm typecheck && pnpm lint && pnpm test && pnpm build` 全绿。
2. 启动 `pnpm dev`（发布验证用安装包），首页点「打开示例项目」，确认 5 条链路完整呈现。
3. 网关设置：文本/图片/视频各配置一个真实或测试供应商；未配置的节点按「预期报错」验收。
4. 回归过程中不修改示例项目内容；需要破坏性操作（删除/断线）在副本项目上进行。

## 2. 九项操作通用预期

先读通用规则，矩阵中只列节点特有行为；未注明即「同通用」。

| 操作 | 通用预期 |
| --- | --- |
| 创建 | 从节点菜单创建 → 画布出现默认尺寸（340×260）卡片，标题为节点名，exec 状态为初始（未运行），可撤销 |
| 编辑 | 双击/卡片内进入编辑 → 修改即时生效，Ctrl+Z 可回退，编辑态不触发全局运行 |
| 拖动 | 拖动卡片 → 连线跟随、端口对齐不漂移，松手后位置持久化，可撤销 |
| 复制 | 选中复制（Ctrl+D / Ctrl+C+V）→ 新节点内容与配置一致、ID 不同、exec 状态回到初始，可撤销 |
| 删除 | Delete → 节点与全部关联连线一并删除，可撤销；删除节点不删除已落盘媒体文件 |
| 连接 | 输出端口拖到输入端口：类型兼容 → 成功；不兼容/Schema 不符 → 拒绝并给出端口级提示；单值端口已占用 → 拒绝第二个上游；重复边 → 拒绝 |
| 运行 | 全局「运行」与卡片内手动按钮产出一致（同一入口 `runNodeManually`，见 [CONSISTENCY_MATRIX.md](./CONSISTENCY_MATRIX.md)）；成功 exec=success，失败 exec=error 且错误进面板 + 日志（`%APPDATA%/canvas-studio/logs/`，无 API Key） |
| 保存 | 自动保存触发 → `project.json` 含节点 props、连线与 graphVersion 递增，无未知 nodeType/portId 被静默写入 |
| 恢复 | 关闭项目重开 → 节点、连线、内容、媒体引用、持久化 exec 状态/媒体完整往返；未知节点类型显示冻结占位并警告，不崩溃 |

## 3. 节点 × 操作矩阵

| 节点 | 创建 | 编辑 | 拖动 | 复制 | 删除 | 连接 | 运行 | 保存 | 恢复 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **文本** text | 同通用 | 多行中文可输入；内容即 out-text | 同通用 | 文本内容一并复制 | 同通用 | out-text → 下游 text 端口（many 可多上游） | 无上游时输出自身文本；有上游时上游文本与自身文本合并（顺序：上游在前） | 同通用 | 文本完整往返 |
| **图片** image | 同通用 | 「导入」选本地图片 → 媒体落盘项目 media 目录，卡片显示预览 | 同通用 | mediaPath 引用同一资产 | 同通用；媒体文件保留 | 无输入端口；out-image → 生图参考图 / 视频首帧等 image 端口 | 原样输出图片资产引用 | 同通用 | mediaPath 相对路径往返后预览正常 |
| **生图** image-gen | 同通用 | 提示词/模型/尺寸配置 | 同通用 | 生成配置复制；已生成媒体引用一并复制 | 同通用 | in-image（可选参考图）+ in-text（提示词，many） | 调网关生图 → 落盘 → out-image；手动「生成」与全局运行一致；网关失败 exec=error 且日志无 Key | 同通用 | 生成图片往返后仍可预览 |
| **视频** video | 同通用 | 提示词/模型配置 | 同通用 | 同通用 | 同通用 | in-image（可选首帧）+ in-text（提示词，many） | 任务式异步运行，运行中可取消（CancelSignal），完成 out-video | 同通用 | 任务状态与产物往返；失败任务可重跑 |
| **音频** audio | 同通用 | 导入本地音频或 TTS 模式填朗读文本 | 同通用 | 同通用 | 同通用 | in-audio（可选，接入后作为音频来源）+ in-text（TTS 朗读文本） | 导入模式原样输出；TTS 模式用上游/节点文本合成 → out-audio | 同通用 | 音频引用往返后可播放 |
| **对话** chat | 同通用 | 多轮消息列表，Markdown 渲染 | 同通用 | 对话历史一并复制 | 同通用 | in-text（many）作为本轮输入 | 每轮对话最后一条助手回复 → out-markdown；连续多轮上下文保持 | 同通用 | 完整对话历史往返 |
| **脚本** script | **不可从菜单创建**（旧项目兼容保留，creatable=false）；旧项目中的脚本节点正常显示 | 剧本文本/字段定义编辑 | 同通用 | 同通用 | 同通用 | in-text → out-json（storyboard.shots）+ out-text（可选） | 剧本文本拆解为分镜 JSON | 同通用 | 旧项目脚本节点往返不丢失 |
| **处理** processor | 同通用 | 未连线时可用固定值 | 同通用 | 同通用 | 同通用 | in-value（any，单值）→ out-value（any） | 上游值原样传递；未连线用固定值 | 同通用 | 同通用 |
| **JSON** json | 同通用 | 字段卡片形式展示与编辑 | 同通用 | 同通用 | 同通用 | in-json（many 汇总）+ in-text（可被 JSON.parse 的文本） | 校验并格式化 → out-json（json.any） | 同通用 | 结构化数据往返一致 |
| **代码** code | 同通用 | 代码编辑；params 配置生成动态参数端口 | 同通用 | 代码与 params 一并复制 | 同通用；连线中的动态参数端口随删除消失 | in-text + in-json + 动态参数端口（类型由 param 定义） | 执行 JS：return 字符串 → out-text，return 对象/数组 → out-json | 动态端口定义持久化 | params 动态端口往返后重现 |
| **分镜板** storyboard | 同通用 | 镜头卡片（画面/台词/时长）可编辑 | 同通用 | 分镜结构一并复制 | 同通用 | in-json 必须符合 storyboard.shots Schema，错误结构连线被拒 | 输出编辑后的完整分镜结构 out-json + 摘要 out-text | 同通用 | 分镜卡片编辑结果往返 |
| **AI 处理** ai-process | 同通用 | 模型/系统提示词/输出模式（text/markdown/json） | 同通用 | 配置一并复制 | 同通用 | in-text（many）+ in-json（可选上下文） | 一次性转换，无多轮历史；json 模式输出经 Schema 校验，失败有具体报错 | 同通用 | 同通用 |
| **循环** iterate | 同通用 | 并发上限/失败策略/重试配置 | 同通用 | 同通用 | 同通用 | in-list 必须符合 list.items Schema | 逐项驱动循环体内下游子流程 → out-items 结果列表；支持取消；中止后可恢复未完成项 | 循环配置持久化 | 中止状态往返后「恢复」可用 |

## 4. 示例项目链路验收（固定底稿）

矩阵过完后，在示例项目上跑通 5 条链（全局运行一次全部 success）：

| 链路 | 路径 | 预期 |
| --- | --- | --- |
| 链 1 | 文本 → 生图 | 生图节点产出图片并落盘 |
| 链 2 | 文本 → 对话 → JSON | 对话回复解析进 JSON 节点 |
| 链 3 | JSON → 分镜板 | 分镜卡片渲染镜头列表 |
| 链 4 | 处理 → 代码 | 代码节点读取命名输入并输出变量 |
| 链 5 | 循环 → AI 处理 → 生图（批处理） | 列表逐项完成，out-items 汇总各产物 |

同时验证：示例项目导出 `.canvasbundle` → 删除 → 再次「打开示例项目」可重新导入。
