# 2026-10-05 全局滚动条与画布品牌入口

## 变更备注

- 所有应用内滚动区域保留原滚动能力，始终隐藏横向、纵向滚动条，悬停与聚焦也不恢复显示。覆盖文档根节点、画布、节点正文、编辑器、侧栏、资产/节点库、弹窗、下拉列表和引用详情。
- 使用应用入口加载的 `assets/scrollbars.css` 统一规则，未来新增区域自动继承；隐藏不改变 overflow，也不保留滚动条 gutter。
- 移除 AI 处理的自绘阅读滑块及专属占位边距，避免公共规则隐藏原生滚动条后仍残留可见滑块。
- 所有画布左上角“项目”文字改为首页 Free Creation 的既有品牌图标，保留项目菜单名称和全部回调。
- 规范已写入 `docs/NODE_UI_STANDARD.md` §19 与 `AGENTS.md`，同时修正旧版“侧栏细滚动条可见”和 AI 阅读滑块要求。

## 验证与交付

新增浏览器门禁 `scripts/test-browser-hidden-scrollbars.cjs` 检查节点长结果滚轮和键盘阅读、末尾可达、画布相机稳定、多个区域横纵滚动、文档根滚动条隐藏及品牌菜单可打开；已接入全量验证。现有 AI 结果回归改为检查无可见滑块且滚动仍可用。

`npm run verify` 通过：133 个测试文件、1495 项通过、1 项既有跳过，另有模型包 2 项测试、28 节点布局/颜色/选中及全部浏览器门禁。变更复核覆盖正确性、可读性、公共样式边界、安全与性能；滚动与菜单回调沿用既有实现，删除自绘滑块同时移除了其观察器和事件订阅。

桌面输出目录：`dist/hidden-scrollbars-release/win-unpacked`。运行产物和截图按仓库规则保留本地，不提交 Git。

桌面包使用独立临时数据目录完成启动、新建项目、品牌图标加载、根滚动条隐藏及菜单禁用检查。桌面“启动 Canvas Studio”快捷方式更新至该版本；当前运行实例保存退出后重新打开即可生效。

本次属于公共呈现与文档修改，不新增执行、模型请求、文件或保存路径，日志影响不涉及，见 `docs/LOGGING_COVERAGE.md`。浏览器验收使用 Chromium，未模拟所有实体触控设备。
