# 变更备注 · 2026-09-28

## 节点与节点库

- 新增“网址节点”：在右侧面板配置名称和网址，点击节点打开对应链接。
- 新增“声音调整”节点：连接一段音频或视频，按倍率或目标时长变速，并调整声量；输出为新的媒体资产。
- 将工作流侧栏入口调整为“节点库”，支持保存和复用单个节点或串联节点；单个节点通过右键菜单保存，移除多选工具栏中的资源库保存入口。
- 画布搜索同时检索画布节点和节点库条目；简化搜索面板初始状态。
- 统一节点内按钮的图标与文字顺序，并收紧语音节点上传控件的点击范围。
