# 变更备注 · 2026-09-27

## 语音节点职责拆分

- 原“语音克隆合成”调整为单一职责的“语音克隆”节点：接收参考语音，向 MiniMax 登记音色并输出 `voice_id` 音色档案。
- 克隆节点不再强制要求朗读文本，也不再自动调用 TTS 生成整段音频。正式朗读由现有“语音合成”节点完成，可通过音色档案端口连接。
- 移除本地 IndexTTS / ComfyUI 的语音克隆入口、执行实现及专用 IPC；MiniMax 辅助提示音按 `prompt_audio` 用途上传。
- 提升克隆节点契约版本至 4。既有画布中的克隆节点仍可打开；此前接入 `in-text` 或 `out-audio` 的连线需按新职责调整。

## 桌面更新、模型与画布体验

- 桌面快捷方式启动流程会检查远端 `main`、同步依赖并从当前源码构建；失败时不启动旧构建。
- 供应商配置会同步到模型目录；节点可见模型能力验证状态，MiniMax 克隆可在节点内调用并显示真实错误。
- 生图节点的提示词区域随卡片高度扩展，生成按钮固定在底部；本地深度视频运行时允许并行启动生图。
- 补充画布生成进度显示、耗时估算与本机样本记录；工作区历史状态 IPC 和存储同步扩展。
