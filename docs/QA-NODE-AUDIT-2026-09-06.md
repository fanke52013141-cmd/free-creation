> 审查对象：`npm run dev:browser`（`http://localhost:5173/` + browserMock），工作区提交 `e0486d7`（2026-09-06 06:52）。
> 审查工具：ZCode In-app Browser（GUI 黑盒交互：点击/拖拽/输入/截图 + DOM/ARIA 状态读取）。
> 范围：23 类节点逐一审查，覆盖①截图审查（排版/遮挡/显示不全）②功能审查（输入输出显示）③配置与运行审查（配输入输出、连线、整图运行、节点关系）。

## 结论摘要

- **通过项**：23 类节点全部可创建，空态文案、端口类型声明（`title` 完整：类型/必填/单多值/连接数）、状态徽章（字数、"JSON 有效"、"未选择模型"、状态灯）渲染正常；类型/Schema 校验拒绝不兼容连线并给出明确 toast；连线曲线渲染、端口状态色（绿=可用/红=必填缺失/灰=无输出）正常；整图运行依赖顺序正确（上游先执行）；运行中心按节点记录 success/failed/skipped、失败原因、输入输出变量与重试/回到节点入口。
- **真实跑通的执行链路**（浏览器可本地执行的部分）：文本 → 处理（原样传递）success 且输出可用；代码节点 `return 42` success（本地 JS 执行 + 语法高亮编辑器）。
- **受限项**（mock 固有限制，与 09-05 结论一致）：生图/对话/配音/AI 处理运行到网关层即给出稳定错误（skipped/failed + 原因），不伪造输出；本地媒体导入不可用。
- **新发现问题 8 项**：2×P1、4×P2、2×P3，详见下文。其中 P1-1（新节点生成位置被顶栏遮挡）为系统性问题，影响 13 类节点首次创建后的可操作性。

## 发现的问题与优化方案

### P1-1 新节点级联生成位置与顶栏重叠，标题行按钮不可点

- **现象**：连续添加节点时，后续节点生成在画布坐标 (162,45)，卡片标题行（含「运行此节点」「打开节点说明」按钮）被顶部应用栏（高约 65px）遮挡且**无法点击**（命中测试被顶栏截获）。受影响节点：拆分/生图/修改/视频/取帧/截取/提音/人声分离/音频/对话/代码/循环/预演（13 类，实测全部复现）。
- **与 09-05 审查的关系**：09-05 已修复"卡片与卡片矩形交集"（自动避让网格生效），但未覆盖"卡片与顶栏重叠"这一场景——避让网格的首行起点仍落在顶栏之下。
- **修复方案**：节点创建落点计算（`NodeCreateMenu` 建节点 + 左侧栏添加入口）将首行起点从当前级联原点下移至顶栏高度以下（`viewport top + 顶栏高 + margin`），或生成后对超出 viewport 顶部的卡片自动平移相机/节点。建议把"卡片 rect 与顶栏 rect 交集为 0"补进避让网格的断言/测试。
- **验收**：连续创建 5 个节点，所有 `.node-card-wrap` 的 `getBoundingClientRect().y` ≥ 顶栏高度；节点标题行按钮可点击。

### P1-2 运行中心打开时，节点配置入口被静默忽略

- **现象**：运行中心面板打开的状态下：点击卡片上「配置裁剪」「配置拆分」按钮（坐标点击与 DOM click 均验证）、单击对话卡片、双击对话卡片，右侧面板均不切换为节点详情，且无任何提示。
- **修复方案**：侧栏面板改为单例状态机（同一时间只允许一个详情源）：任何"打开节点详情"请求先关闭运行中心再打开详情；若产品上要求互斥保持现状，至少给出"已关闭运行中心并打开详情"的 toast。
- **验收**：打开运行中心 → 点任意节点配置按钮 → 节点详情面板打开。

### P2-1 图片节点「导入图片」零反馈

- **现象**：点击图片节点空态的「导入图片」按钮，无文件对话框、无 toast、无错误（browserMock 的 `pickMedia` 返回 err 信封，但 UI 未消费）。
- **修复方案**：导入按钮统一消费 `IpcEnvelope`，`ok:false` 时走全局 Toast（文案可用错误 message「浏览器演示模式不支持本地媒体导入」类）。桌面端真实路径行为不变。

### P2-2 对话节点"选中 → 右侧面板对话"未发生

- **现象**：对话卡片空态提示"选中此节点 → 右侧面板对话"，但单击选中、双击均不打开右侧面板（与 P1-2 在运行中心关闭的状态下同样复现）。
- **修复方案**：实现"选中对话节点即打开对话面板"；若设计上改为显式入口，则修改卡片文案并增加入口按钮。

### P2-3 「打开 3D 预演台」按钮无响应

- **现象**：预演节点卡片按钮点击（坐标与 DOM click 均验证）后无遮罩层、无路由变化、无报错；页面 canvas 数量不变。
- **修复方案**：接通 previs 覆盖层/独立路由入口；浏览器 mock 下至少给出"3D 预演台需桌面版"前置提示，不要静默返回。

### P2-4 缺少必填输入时节点级运行静默

- **现象**：裁剪（缺源视频）、循环（缺列表）在必填端口为空时点击卡片「运行此节点」，无 toast、运行中心无记录、状态灯不变。
- **修复方案**：节点级运行前置校验失败时：① toast 列出缺失的必填端口名；② 运行中心记录一条 `skipped`（原因=缺少必填输入），与整图运行行为对齐。

### P3-1 数据(JSON) 节点在整图运行中无执行记录

- **现象**：数据节点填入合法 JSON（卡片显示"JSON 有效"）后顶栏运行，运行中心仅有文本节点记录，无数据节点记录。推测为"输出无下游消费者被剪枝"或调度遗漏，需代码层核实。
- **修复方案**：确认执行引擎对"死端节点"的策略；若有意剪枝，运行中心应显示"未纳入本次运行（无下游消费）"，避免"看起来没跑"。

### P3-2 预演节点卡片命中热区异常

- **现象**：预演卡片点缩略图、点卡片空白区域均无法选中（其他节点卡点空白区可选中）；仅能通过画布框选/全选删除。结合卡片标题行被顶栏遮挡（P1-1），首次创建后几乎无法正常选中。
- **修复方案**：排查 `NodeCardView` 预演卡的 `stopEventPropagation` 配置与卡片根元素命中区域（对照 HANDOFF §5 第 2 条"tldraw 交互铁律"）。

## 已验证正常的全局能力
