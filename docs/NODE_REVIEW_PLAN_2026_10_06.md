> **复核中：以下原始审查结论属于历史初稿，不可作为当前缺陷清单或整改完成证明。** 当前裁决和新证据见 [逐项复核与整改验收](./NODE_REVIEW_REMEDIATION_2026_10_06.md)。尤其是原稿把固定网格测试的遮挡归因于自动放置，以及把“字段提取”当成默认原样传递的结论，均已撤回。二次定向复跑实际只包含分镜板和导演台，未包含代码节点。

本次审查覆盖当前 28 个可创建节点：初始卡片、填充内容态、输入/输出侧栏的首尾位置，以及自动测试中的创建、端口、运行、产物和重载状态。审查按照 [节点 UI 规范](./NODE_UI_STANDARD.md)、[画布呈现规范](./NODE_CANVAS_PRESENTATION_SPEC.md)、[引用规范](./NODE_REFERENCE_SPEC.md) 与 [节点合规矩阵](./NODE_COMPLIANCE_MATRIX.md) 进行。

## 审查结论

节点的颜色分组、标题行、卡片外壳和大多数主操作已经形成稳定的共同样式。主要问题集中在三处：节点实际尺寸与自动摆放/画布固定工具栏之间没有充分协调；全屏导演台的层级低于画布顶栏；多类型端口只显示默认类型时，其他输出缺少直观的连接入口。模型类节点的卡片和说明侧栏可见，但本轮没有调用第三方服务，因此不能据此宣称图片生成、视频生成、AI 对话、AI 处理、语音合成、声音克隆或音色设计已经完成真实供应商端到端验证。

| 级别 | 问题与证据 | 不处理的影响 | 建议 |
| --- | --- | --- | --- |
| P1 | **画布可操作区域被固定工具栏覆盖。** 真实 Electron 矩阵在 50% 缩放、较多节点的代码流程中，`in-json` 命中坐标落在底部 dock 按钮上；导演台发布按钮也被 `canvas-topbar` 拦截。 | 节点端口和全屏工作区的关键动作会无法点击；自动布局到画布边缘后，流程看起来存在却不能继续连线。 | 统一计算工具栏安全区；节点自动放置和自动取景避开固定工具栏。Modal/工作区层级必须高于顶栏，增加真实指针命中回归测试。 |
| P1 | **自适应宽度节点遮挡自己的异类型输出端口。** 分镜板 JSON→表格→运行成功；接文本节点后，新增节点覆盖了分镜板的 `out-text`，该连接点被遮挡逻辑隐藏，重复测试都无法从该输出发起连接。 | 用户无法发现或连接有效输出，导致分镜摘要无法进入文本或 AI 节点。 | 节点摆放以卡片实际 bounds 和端口扩展范围为依据；多类型可选端口应有可发现的替代连接入口，不能只在内部契约或侧栏中存在。 |
| P2 | **数据处理节点可保存不兼容的模式/值组合。** 当前初始配置为字段提取；无上游连接时填写纯文本，运行会失败并报“提取字段模式只支持 JSON 输入”。连接 JSON 后提取字段和重载均通过。 | 用户在运行后才看到错误；固定文本与字段路径的模式选择容易不匹配。 | 用有效输入类型决定字段提取可用性；不兼容时在卡片上即时提示或阻止运行，并明确引导切换到字符串模板。自动配方需遵循当前“提取字段 / 字符串模板”的定义，不能期望默认原样传递。 |
| P2 | **模型配置节点信息密集，供应商真调用未覆盖。** 视频、图片生成/编辑、语音、克隆、音色设计、对话与 AI 处理含多组参数；本轮模型请求保持关闭。 | 用户需要在密集卡片中找关键输入；仅凭本地契约/驱动单测无法确认真实供应商响应、费用、失败提示和结果展示。 | 优先折叠低频高级参数、保留核心输入和运行按钮；另做有明确供应商/模型/费用边界的真服务验收后再宣称端到端通过。 |
| P3 | **媒体节点的浏览器“内容态”截图没有真实媒体。** 自动视觉样例只改节点标题/文本，不会创建磁盘媒体资产；媒体卡片的初始图和内容态相同。 | 单看截图包会误以为空媒体预览没有实现，或把模拟内容当成实际输出。 | 保留明确的 fixture 标记；把 Electron 实际导入、剪裁、取帧、视频处理及音频产物截图归入同一索引，模型节点则标明未接真实供应商。 |
