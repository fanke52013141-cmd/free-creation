# 白模视频渲染与验收规范 v2

2026-10-06。适用于 video-clay，端口保持 in-video → out-video，契约版本仍为 1；渲染配置版本为 2。

## 目标与边界

保留构图、动作、可见轮廓；以无源纹理的哑光白材质呈现大面体积。算法使用相对逆深度与估计视角构建可见表面法线，不承诺米制尺寸、隐藏面、可编辑网格或任意视角。环境遮蔽为屏幕空间近似，不能当成完整场景投影。模型估计不到的五官/细杆结构不能靠光照补出。

## 实施算法

- 每镜头分别推理、以该镜头的深度分位范围稳定归一化。切镜由缩小灰度画面的直方图与像素差检测，不逐帧重新拉伸范围。
- 相对逆深度经有界参数的指数映射转为艺术化距离；估计水平视角 50°，在透视空间计算法线。默认视角可调 25–90°，无需假造相机内参。
- 双边滤波保边；法线沿深度差更小的一侧计算，避免直接连接前景与背景。
- 法线再按输出尺寸缩放的两层邻域平滑，邻居按深度差加权，差值达到 0.06 时完全拒绝，避免跨人物与背景融合。只处理几何朝向，不读取源颜色；降低阶梯噪声形成的细黑边，同时保留大面曲率。细杆、发丝等极小结构可能变柔，不能以这种平滑宣称恢复了缺失五官。
- 主光、补光、半球环境光、哑光反射及显示 gamma；多方向局部环境遮蔽拒绝较大深度断层，抑制轮廓暗晕。不用原图颜色、纹理或边缘描线补材质。
- 时间处理使用小尺寸光流，回投历史深度并检查双向一致性、亮度误差、深度变化、越界；切镜及遮挡变化拒绝历史，稳定程度 0 可关闭。最大历史混合权重 0.5。
- 新渲染模型启用 PyTorch SDPA，避免没有 xFormers 时显式生成巨大注意力矩阵。原配置使用原计算，注意力等价性独立测试。

## 预设和质量

节点展示“白模效果”和“质量”两个选项；侧栏提供立体程度、光线方向/高度、环境光、阴影、时间稳定、视角估计、音轨与恢复默认。沿用公共 AppSelect、节点引用和高度规则，不新增配置按钮或自绘滚动条。

柔和/立体/结构预设修改光照和深度程度；用户微调后仍保存实际数值，运行以数值为准。快速/标准/精细推理 input_size 分别 518/644/770；选择质量同时设置输出长边上限 512/768/1024，可在侧栏另调输出尺寸。模型内部会按长宽比与 14 的倍数调整实际张量，因此不能把档位数值称为实际输出分辨率。提高档位仍使用当前 Small 模型，未下载或宣称升级到更大模型。

默认 v2：柔和、标准、768 输出上限、立体 1.5、方位 315°、高度 45°、环境 0.42、阴影 0.35、时间稳定 0.6、视角 50°、保留音频。

## 历史兼容与追溯

v1、无版本、空/损坏旧配置均保持浮雕算法、518 推理和原参数；用户点击“升级白模效果”才改版本。创建入口读取节点 Spec.initialConfig，将新白模节点显式初始化为 v2，不在加载/导入时补写默认配置。恢复默认会显式切换到 v2。不重写原视频、已有结果或用户项目；新产物沿原执行器保存独立媒体资产。新旧配置均须序列化、保存恢复。

## 验收规则

固定同源样片，保留原视频、旧算法、相同深度的新算法和标准新算法的并排结果，不挑帧替代视频。至少检查平面、曲面、深度断层、切镜、遮挡变化、快速运动、多个预设。真实样片用于视觉审查；合成几何用于已知法线与时序行为校验，两者不能互相替代。

逐项记录：可读体积、轮廓暗晕、拖影、闪烁、未恢复结构；帧数/尺寸/音轨、全片解码、推理/渲染耗时、CUDA 分配峰值；真实节点运行、失败/取消、独立媒体、保存与重开。源码或导出成功不能证明视觉达标。多人、头发、复杂动作的覆盖缺口必须列出。

后续大模型/米制模型需独立同源比较效果、时间、显存和模型许可；三维重建另立方案，不隐藏进当前参数。
