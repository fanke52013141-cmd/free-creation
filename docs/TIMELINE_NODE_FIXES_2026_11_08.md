# 2026-11-08 轨道线节点三项问题修复

## 1. 框选时选框消失

**现象**：框选画布节点、选框扫过轨道线节点时，选框像消失了一样。

**根因**：选中时间线片段时，代码通过 `editor.setEditingShape(shape.id)` 强行让画布进入
「编辑态」，只为拦住 Delete 快捷键。tldraw 进入 editing 状态后，框选/拖拽的指针行为会异常，
选框在跨越该节点时被中断。

**修复**：
- 删除 `setEditingShape` 抢占编辑态的逻辑；
- Delete/Backspace 改由已有的 `window keydown capture` 拦截（只删片段、不让画布删节点），
  不需要进入编辑态；
- 浏览器实测：框选跨越轨道线节点后，选框可见且能正常选中多个节点。

## 2. 音频放入轨道后全屏不能播放

**现象**：把音频拖到轨道线，进入「全屏编辑」后点播放没有声音，预览区还显示「没有媒体可供预览」。

**根因**：全屏播放器只取「画面片段」（`visualClipAtPlayhead` 明确排除 audio），
播放逻辑也只绑定 `<video>`；音频片段完全没有对应的媒体元素，也不参与播放/暂停/音量。

**修复**：
- 新增 `audioClipAtPlayhead`（跳过隐藏/静音轨道），全屏预览增加 `<audio>` 元素；
- 播放/暂停、播放头 seek、音量滑杆同时驱动音频（与视频一致）；
- 没有画面但有音频时，预览区显示音频占位（图标 + 片段名 + 「音频轨 · 播放时出声」），
  不再显示「没有媒体可供预览」；
- 浏览器实测：1 秒音频片段，点播放后 `audio.paused=false`、`currentTime≈0.66`、音量 0.8。

## 3. 连接两个节点后轨道线拖不动/选不中

**现象**：一旦把素材节点连到轨道线，轨道线节点就拖不动、有时也选不中。

**根因**：
1. 引用素材条根节点 `.tl-refs` 被整体标了 `data-node-pointer="control"`，
   导致这条新增的整行（含标题、留白）都变成「控件」，按下只选中、不启动拖动；
2. 上面第 1 条里的 `setEditingShape` 也会让后续拖动/选择异常。

**修复**：
- 移除 `.tl-refs` 根节点的 blanket control，只保留真正的素材按钮/按钮控件；
- 同时移除 editing 态抢占；
- 浏览器实测：连接后分别从「时间轴空白、引用素材条、工具栏空白」拖动，节点都能移动；
  框选也能正常选中。

## 4. 吸附不生效 & 同轨图片/音频重叠

**现象**：开着自动吸附，从素材库/引用素材拖进已有内容的轨道，没有接到内容后面；
图片和音频还能在同一轨道重叠。

**根因**：
- `snapDropStartMs` 对音频直接跳过磁吸（`isVisualKind` 判断），且视觉片段只吸到
  「最近边缘」，落点与片段相交时可能落到片段起点导致 `addClip` 拒绝，看起来"没吸附"；
- `overlappingClips`/`freeStartMsFor` 明确允许音频互相叠放、也忽略音频对画面的占位，
  所以同一轨道可同时出现图片和音频。

**修复（2026-11-08 用户裁决：同轨不再允许任何重叠）**：
- `overlappingClips`：图片/视频/音频一视同仁，同轨只要有交叠即冲突；
- `freeStartMsFor`：音频也要避让，从落点向右找第一个能放下的空档；
- `snapDropStartMs`：
  - 落点与已有片段重叠 → 直接吸附到该片段末尾（"有内容就接在后面"）；
  - 落在空白区 → 吸到最近合法边缘（片段起点/末端），没有候选则顺延到首个空档；
  - 音频/图片/视频统一处理；
- 移动/裁剪同样受新的同轨不重叠约束；旧项目里已有的重叠片段会保留显示，
  直到被再次移动/裁剪时要求避让。

**验证**：`test/timeline-model.test.ts` 更新并新增 46 项通过——同轨音频不再允许重叠、
音频落轨参与磁吸、图片落到音频占用轨会接到音频末尾、相交落点接到片段末尾。

## 验证

- 浏览器端到端：
  - 连接图片素材到轨道线后，从 lane/引用条/工具栏拖动均成功；
  - 框选跨越轨道线节点，选框与选中结果正常；
  - 音频轨全屏播放成功，`audio.paused=false` 且播放时间推进；
- 新增 `test/timeline-node-fixes.test.ts`：
  - 音频片段命中/静音轨排除；
  - 预览包含 audio 元素与音频占位；
  - 引用条不再 blanket control、不再 setEditingShape；
- typecheck、lint（改动文件）、生产构建通过。

## 边界

- 同一时刻只播放播放头上最上层的一条音频轨（尚未做多音频轨混音）；
- 视频素材自带原声仍由 `<video>` 播放，音量滑杆统一控制；
- 静音/隐藏轨道不参与预览音频；
- 需要叠音时请放到另一条轨道；旧项目里已经存在的重叠片段不会自动拆开。
