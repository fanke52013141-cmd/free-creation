## 4. R11 执行记录

### 4.1 凭据与隔离

- 用户提供一次性 Vidu Token；只通过仓库外安全文件交接。
- 验收进程读取后立即删除文件；Token 未进入命令行参数、QA 回执、日志或报告。
- 桌面宿主、SQLite、项目、媒体与诊断均使用隔离数据目录；结束后整目录删除。
- 未上传数据库、密钥或媒体。

### 4.2 单次付费路径

执行入口：[run-vidu-single.cjs](../../../qa/r09-r11-acceptance-20261126/r11-live/run-vidu-single.cjs)

实际路径：

1. Vidu CLI `task cost`：`headtailimg2video` / `3.2` / 1s / `1080p` / `h264` / `transition pro`。
2. `quota before` = 9191；quote = 30 credits，`can_submit=true`。
3. 隔离桌面宿主启动；`provider.save` 写入 legacy Vidu provider（Token 仅入设备密钥库）。
4. `project.create` / `project.open`；导入两张 1280×720 首尾帧；`graph.patch` 建两个图片节点、一个视频节点和两条有序 `in-images` 边。
5. 视频节点显式 `modelKey=vidu-r11::3.2`、`mode=first-last-frame`、`params={duration:1,resolution:"1080p"}`。
6. **仅一次** `node.execute`（`confirmPaidRerun=true`）；之后只读轮询原任务，不重投。
7. `run.get=completed`；`output.get` 返回 `out-video`。
8. 复制成片、`ffprobe`、完整 FFmpeg 解码、只读查询原上游任务与额度。
