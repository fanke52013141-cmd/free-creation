## 用户路径

主控并行派发两路独立视频专业任务，各自有抽帧审核与一次返工预算，两个审核共同控制下游。第一路返工结果未知时，另一路仍能审核、返工并保存已批准成果；下游继续等待全部审核。重开后只核对并继续原未知任务，禁止新增生成请求。人工返工或协作返工的等待同样不能遮挡后续支路的已完成事实。

## 代码

- CoordinatorReviews 遍历所有审核周期，将人工/协作/未知等待累计到本轮末尾；有确定进展优先返回 again。
- 主控在审核等待时仍收集普通专业任务的已完成成果；有进展先重新检查审核，再进入等待。
- 保持审核版本门禁、总预算、独立任务及命令、显式人工继续、停止/迟到守卫。没有扩大已授权节点类型、并行上限或引入新的执行器。
- 新增 --parallel-review 隐藏桌面夹具：真实画布/IPC/SDK/公共执行器与四帧解码；供应商协议替身限定四次生成、四次审核，初始 POST 必须重叠。每个新返工快照固定原目标/输入及被拒版本和反馈。
- 并行截图验收等待主控实际 DOM 出现“资产已完成”和 completed 阶段，防止后台完成事实配上旧等待画面。
