# C3.3 建图预览、固定版本审核与人工复审

日期：2026-10-13。接续顺序协调首包；本文只描述本次实际实现，不等于整个 C3.3 完成。

## 画布用户路径

搭建 Agent 选择文本模型，启用 graph.preview@1，在允许范围选择一个 text@3 材料节点，填写文本模板流程目标。点击“生成建图预览”走公共 Agent executor；主进程保存有限提案，原图不变。节点内显示步骤、模板、参与方式与拟创建数量。人点击“提交图变更”后，主进程核对语义版本，renderer 通过公共节点注册表和 createEdge 创建图；一组历史操作可撤销。保存确认后才显示已提交，不自动启动流程。保存响应不确定时保留图并核对确定性 ID，重复提交不复制节点。

首批建图能力 sequential-text-template@1：1–4 个文本模板步骤，创建主 Agent、状态机、独立专业 Agent 与每步的数据处理节点。模型只填写有限步骤，可信宿主生成 ID、模型绑定、工具权限、端口与显式控制/状态关系。模板必须包含 {{value}}；专业任务仅调用已授权的数据处理节点。不能宣称自由写作、媒体生成、代码或全节点建图已支持。数据边仍是 DAG，控制/状态关系独立保存在 config。

审核节点选择模型、填写标准、选实际连线接入的文本/JSON 对象和下游门禁，点击“审核当前版本”。宿主固定输入资产，模型只返回 passed、feedback 和对象问题；reviewId、cycleId、规则版本、轮次、来源与资产版本由宿主填充。报告和反馈端口由同一记录投影，可提交固定资产。质量“否”仍是节点执行 success；模型/解析失败没有质量结论。

人工路径：审核“否”后保留材料和报告，下游手动/Agent 命令均阻断；人在负责修订的节点明确提交新内容，再点击复审。通过记录必须来自主进程持久报告，画布报告和成功运行相符，且当前来源、运行身份、连线、标准、模型与绑定均匹配。新版本或新规则使旧通过记录失效。Agent 命令还核对输入清单使用已审核的同一固定引用。初审加 maxReworks 次复审有界；同一版本返回已有报告，不重复消耗质量轮次。stop 策略拒绝隐式开启下一轮。

## 持久化与日志

SQLite v16 增加 flow_builds、flow_reviews，仅存提案和运行事实，不建立另一张可编辑任务拓扑。项目保存仍沿现有文件/SQLite 保存协调器，不宣称两个存储跨事务原子。同步创建失败删除本次新记录；保存响应不确定保留现场并要求核对。

建图/审核 IPC 复用 agent.desktop 操作开始与唯一终态；模型复用 model.request，实际执行/保存/资产复用原生命周期。只记录身份、阶段、调用数量和规范化结束原因。预览 inspect 轮询不逐次写日志。提示、材料、回复、推理和密钥不入诊断；测试用隔离临时项目并清理。

## 验证和剩余范围

定向 41 项通过（含 SDK 3 项和物化固定资产端口回归）：预览持久化和重开、重复提案、取消、版本冲突、完整提交核对、固定审核版本、报告/反馈同源、伪造报告、技术失败、修改中断、审核门禁、轮次耗尽和停止策略。桌面合成模型建图与人工复审均通过双进程路径。

真实 Seed 2.1 turbo 建图完整路径通过（12 次请求，实际诊断脱敏通过），包括建图提案、重开提交、生成图真实执行、独立任务和最终文本资产。真实审核双进程拒绝→人工 v2→通过→释放下游→v3 使旧批准失效路径通过，6 次请求，实际诊断脱敏通过。验收标准为明确的文本前缀检查，不证明任意业务质量判断必然正确。空工具终帧按无效动作失败，保留失败证据；新隔离测试不是对原任务自动重试。

未支持：任意节点能力建图；画布幽灵卡片空间预览（当前预览在搭建节点中）；主 Agent 自动触发审核；纯 AI 与人机协作主体自动创建返工任务；负责节点上的审核反馈投影；主控接续人工修改的子任务；并行、媒体自动协调、独立状态机输出与完整 C4 恢复/迁移。配置中的 rework 目前仅开放明确人工新版本复审，不代表自动返工已支持。

唯一后续：接主 Agent 的审核控制与三类主体的有界返工任务，并验收反馈、固定原始输入、拒绝资产、预算、人工等待及新任务接续；随后完成 C3.3 未覆盖项，再进入 C4。
