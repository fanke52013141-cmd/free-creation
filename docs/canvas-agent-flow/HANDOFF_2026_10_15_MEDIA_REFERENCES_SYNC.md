## 已知边界

- 历史生成视频若没有内容摘要，项目包仍校验媒体存在、身份与 MIME，但不能证明同 MIME 的历史内容没有被替换；不能冒充已验证运动参考，应使用普通视频素材重新固定。
- 单路参考音频、提示词包、多路视频、视频视觉理解/审核、并行媒体调度尚未开放。已有手动节点能力不等于已通过 Agent 调度适配。
- 没有可信供应商查询能力时保持 unknown，不自动重发。现有官方 Ark 核对边界保持；本地停止不等于远端已撤回，不自动以混合 DELETE 证明取消。
- 未新增固定媒体导入中的强杀/掉电、全部媒体解码格式、恶意解码器、磁盘损坏和超大包流式化验收；既有包大小/条目限制保留。文本项目包强杀通过不能外推为完整媒体故障矩阵完成。
- 本次仅同步源码，**不生成或发布安装包**，不修改个人模型配置，不开展旧项目迁移专项。
