# 单路参考音频接入 Agent Flow（2026-10-15）

## 用户路径与范围

普通音频素材 `out-audio` 接 video@7 的 `in-reference-audio`，明确选择 reference 模式。主 Agent 分派专业 Agent，通过公共 node.execute/executor 生成视频；结果未知时保留原命令/任务，关闭重开后明确核对与继续，产出固定视频成果。音频版本可放回画布播放、选中、拖动与双击预览；正式项目包往返后预览及普通输出对应导入的新固定版本。

首版最多一路音频、每个固定参考音频最多 20 MiB，可组合已支持的固定图片、单路视频和最多一路文本；实际能力、数量和供应商文件大小限制继续由既有模型能力/参考素材校验裁决。普通端口、video@7 和手动节点不改版。音频作为视频任务参考，不开放配音/音乐生成节点的 Agent 执行，不开放提示词包、多路音频/视频、媒体理解审核或并行调度。

## 实现

- 普通 audio 素材与 renderer 共用确定性投影。main 从保存的项目快照提交固定音频版本，核对项目媒体身份、相对路径、真实路径、MIME、大小及 SHA-256；每次读取再次复核文件；项目包实际固定音频字节也执行 20 MiB 上限，超限在项目可见之前拒绝。固定音频必须有有效摘要，不沿用历史生成视频的无摘要兼容例外。
- 专业任务与命令账本按声明端口冻结输入。网关逐一匹配固定引用/来源与媒体列表，异步编码后校验实际字节及 MIME，再发送 audio_url/reference_audio。绑定原任务的音频列表，列表变化不以重新生成绕过原任务。
- 停止意图、unknown 占用、重开继续和多进程锁复用原视频链路。停止不等于远端撤回；没有可信远端事实时继续保持未知，不自动重发。
- 音频固定预览读取 pinnedOutput，普通 out-audio 同步携带内容摘要；音频节点详情的资产版本面板可实际提交新版本并放到画布，固定音频禁止再次提交伪造新版本。播放控件独立拥有指针，预览表面仍按公共规则选中/拖动/双击。没有“创建可编辑副本”或替换固定版本的入口。
- 项目包扩展固定音频类型、摘要必填、实际字节核对，沿已有流程重映射媒体/资产/版本/节点与嵌套引用。数据库事务成功后显示项目，旧命令/执行/批准权威不导入。

## 日志检查

日志影响：复用公共执行与项目迁移生命周期；不新增第二套执行器或重复终态。

| 路径 | 事件/阶段与职责 | 关联与敏感信息边界 |
| --- | --- | --- |
| 准入、固定输入、执行 | agent.desktop/coordination、command.operation、公共 node/model/task；main/公共 executor 负责 | project/node/task/command/trace/span/固定版本；只记录受控阶段、数量、ID |
| 文件或版本异常 | ASSET_AUDIO_CHANGED / source-projection、audio-integrity，沿资产 IPC 或 Agent 失败终态返回 | 不记录文件名、绝对路径、音频字节、Data URL、提示词或密钥 |
| 网络未知、停止、恢复 | 既有 video 任务控制、恢复 trace 和原命令身份 | 不写假成功，不重复 POST；不外推真实供应商撤回 |
| 成果、导出/导入与回滚 | 公共 media/asset/save、project.transfer.started/committed/failed | 复用事务和回滚错误，不把诊断当恢复权威 |

日志抛错不改变业务结果的底座行为保持，按全量日志测试回归；无逐帧/轮询重复事件。新增固定音频失败使用安全枚举，旧记录继续可读。桌面验收扫描实际诊断中的测试正文/假密钥、图片/视频/音频 Data URL 和媒体字节前缀，并核对开始与唯一终态。
