# R09 项目保存的临时文件刷盘

2026-10-16。接续 [42 包](42-r09-local-reliability.md)。此前 41/42 包未提交改动保持；本包不调用供应商、不操作用户项目、不更新安装包。

## 画布用户路径与交付范围

隔离项目保存文本基线，主文件损坏时从有效备份加载。编辑后分别注入临时文件半写、刷盘 EIO、转正 EIO 和 SQLite 写满；正式画布保存协调器应拒绝保存、显示失败，未提交编辑不显示为已保存。每次结束 renderer 并重开，应恢复基线和原版本；解除故障后明确编辑重试只提交一次。工作台配置仍保留图版本。

本包将原三次重开扩为四次，并在正式项目仓库的两条保存路径（图、工作台配置）加入同一个临时文件刷盘屏障。`writeFileSync` 返回只表示写入接口完成，原路径没有显式请求操作系统刷出缓存；现在完整写入 `.tmp` 后以可写文件描述符调用 `fsyncSync`，关闭描述符后才轮转有效主文件并转正。刷盘失败走 `flush-tmp` 阶段并保留原快照，阻止索引提交。

未新增业务自动重试、模型请求或第二套保存路径。项目创建/克隆/导入、媒体落盘和 SQLite 的耐久策略不在本包修改范围。文件刷盘不能保证之后目录重命名、文件与 SQLite 跨介质原子提交或设备断电耐久性；Windows 目录刷盘及真实物理掉电仍待专项验收。
