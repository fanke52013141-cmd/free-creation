2. **媒体调用是隔离夹具验收。** 真实 Electron 画布、公共 executor/IPC、SQLite、保存重开、图片和视频解码参与验收；供应商响应与 SDK 决策为合成协议夹具，没有请求付费视频，不代表真实供应商计费/撤回或模型自主决策验收。
3. Agent 视频仅开放文本生成和单张首帧：首帧最多 20 MiB，一个图片版本、可选一路文本。首尾帧、多图参考、音频/运动参考、提示词包、视频内容理解/视觉审核、并行媒体调度未开放。图片使用固定引用和摘要，不复制原文件；原文件变化时阻断读取/执行。

5. 同机共享数据目录的竞争验收不代表跨机器租约、物理掉电/fsync、磁盘损坏或全部长期故障组合完成。
6. 各分包中「未提交/推送」和「下一包」是当时的开发记录；本总 handoff 是此次源码同步入口，不把早期验证数量替换为最终数字。
