## 用户路径

用户遇到问题后导出指定 trace 或时间范围的诊断包。`manifest.json` 除当前导出会话外，还列出范围内实际事件所属会话的环境信息，支持核对跨应用重启或升级前后的版本。历史会话丢失、格式损坏、身份不符、不可读或没有环境字段时，保留对应 sessionId 并设置 `environmentAvailable=false`，不把当前版本套到历史事件上，也不阻断事件导出。

manifest 保留 `canvas-studio-diagnostics-bundle-v1` 格式及原字段，新增 `sessions` 和 `omittedSessions`。每个会话包含 sessionId、environment、environmentAvailable。environment 只允许校验后的 appVersion/electron/chromium/node、平台、架构、packaged 和十六进制 commit；未提供的字段省略，不编造构建号。当前导出会话取初始化时的内存快照，历史会话只读原会话文件，不重写旧记录。

最多输出 128 个会话（含当前会话），超限在 omittedSessions 中明确计数。历史路径由受限 sessionId 构造，拒绝路径片段；stat 大于 64 KiB 的会话文件不读取。此检查不是对并发增长文件的流式硬上限保证。原 ZIP 事件数量、容量与原子落盘逻辑保持。
