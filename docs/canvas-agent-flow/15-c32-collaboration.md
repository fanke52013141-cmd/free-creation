# C3.2：协作目标修订与人工过渡

日期：2026-10-13。范围：专业、人机协作 Agent 的节点内讨论、意见、版本选择与显式任务修订。主控协调、AI 审核返工与完整崩溃恢复仍待后续；合成模型桌面路径已通过，真实豆包讨论兼容仍待接续，状态以开发台账和交接文档为准。

## 画布用户路径

1. 配置人机协作的专业 Agent 并启动；目标和输入由保存画布固定。卡片“查看协作”打开本节点的协作分页，保留画布和节点身份。
2. 任务存在后可保存讨论笔记，包括运行过程中。笔记不修改任务、调用模型或执行工具。人工等待时可明确点击“与 Agent 讨论”，得到本节点的 AI 回复；本轮没有业务工具，只提供建议。
3. 在人工等待阶段输入反馈，选择已确认回执中的交付版本，可先查看完整内容。“提交意见与选择”保存人工决定；回卡片明确继续后才采用。默认未选时由 Agent 检查真实回执；人工选择后最终输出必须一致，否则阻断，不伪造通过。
4. “提交拒绝意见”保存拒绝，明确继续后原任务阻断并保留意见/回执。可回协作分页采用新要求，或停止原任务；不自动审核、不自动重复执行。
5. 修改“新目标”，必要时在材料节点编辑并保存正文，或选择该来源端口已提交的历史版本。点击“采用为新要求”保存画布目标，main 核对范围、真实输入和固定版本后，原任务标记已被替代，新任务准备为待启动。新任务引用 parentTaskId，原目标、输入、检查点和回执不改写。
6. 返回卡片，确认“新修订待启动”并明确启动。新任务使用新的命令身份与预算，旧工具不隐式重放。后续人工等待、重开继续和固定资产输出沿 C3.1b 公共路径。

当前 AI 讨论、意见提交和版本选择发生在持久人工等待阶段；运行中只开放保存笔记。任务创建前的 AI 讨论、任意结构改图、工具/模型/Skill 权限变更和跨来源替换不在本包。旧运行快照若没有 C3.2 scopeRevision，仍可按原要求继续；要改目标需停止并新启动，不能猜测旧范围。

## 数据与一致性

- SQLite v14 新增 flow_agent_collaboration，记录绑定真实任务 thread 的事件；project/task 删除沿外键级联。事件有 eventId、协作 revision、taskId、waitRevision、签名和正文，最多 40 项。AI 回复最多 8192 字符，讨论请求上下文最多 128 KiB，单次超时 30 秒、无自动重试、无业务工具。
- 消息是交流记录，不投影成正式资产，也不改变普通数据边。已有固定输出、nodeRun/nodeResult、预算和 C2 回执协议继续使用。
- 重复事件同意图去重；同 ID 异意图、过期任务/等待/协作版本、非当前项目/主窗口/主 frame 均拒绝。继续必须携带观察到的任务和等待版本。拒绝旧响应不能改变新准备任务的状态。
- 人工反馈和固定选择进入持久 response/checkpoint，再提供给下一次决策。选择只来自本任务 committed 回执，正文和回复不能声明成功。纯 AI 路径没有必经人工等待。
- 目标修订允许改本 Agent 目标和已授权文本/JSON 材料正文；节点、边、角色、配置、Skill/工具权限、处理节点契约保持原范围。范围摘要由 main 从保存图计算。选历史版本必须匹配同项目、同来源节点/端口，引用由资产库验证；不允许自由注入内容或扩大范围。
- 原任务取消、新任务创建和采用事件同一 SQLite 事务提交；任一步失败恢复原任务状态。画布目标保存先于该事务，若 admission 失败，保留编辑并显示错误，旧任务不自动继续；需核对/撤销目标或停止重新启动。
- 新目标采用后卡片立即更新到准备状态，再由公共 executor 明确启动。保存重开保留准备任务，不误标成运行中断；已确认回执和旧固定材料不覆盖。

## 验收与日志自查

定向覆盖讨论去重/冲突、无隐式执行、过期响应不污染新任务、范围/外国引用拒绝、修订事务回滚、历史材料不变、人工反馈进入上下文、拒绝持久化、选择不一致阻断、工具不重放、工具禁用的讨论 SDK 及正文脱敏。实际隐藏 Electron 两进程路径使用正式协作分页、输入、按钮和公共运行/保存，验证讨论/回复/反馈、准备不执行、新启动、版本选择、重开继续与固定成果。

按 LOGGING_CHANGE_TEMPLATE：协作操作复用 agent.desktop started/completed/failed，补允许的 action；project/node/task/trace/span 关联，phase/code 定位冲突或失败。讨论请求沿 model.request 生命周期，正文/回复/目标/资产/密钥不记录。任务、checkpoint、节点、项目保存、资产与 C2 回执沿公共入口，不重复业务终态。普通卡片刷新不新增日志。日志写入失败不改变业务结果；实际诊断扫描与终态配对结果登记台账。

未覆盖：任务/讨论的模板导入导出及引用迁移、长会话摘要与清理、AI 讨论被停止时供应商远端取消、主控协调、多 Agent、状态机执行、AI 审核与有界返工、完整崩溃裁决。此包不把手动拒绝等同 AI 审核，也不声称任意目标会被模型正确完成。
