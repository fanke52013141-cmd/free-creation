## 3. 新旧分界

已知问题：旧方案先建立独立任务/工作区系统，再让画布与它绑定；已撤回实现没有完成成果落在画布上的产品路径。

本方案由上帝 Agent 构建主 Agent、专业 Agent、状态机、能力与成果节点组成的画布图。后台命令、存储、执行和恢复只为同一张图服务，不引入另一套可编辑任务拓扑。

原来的 CLI/MCP/headless 实现仍处于下线状态。当前方案不恢复旧接口；将来如需要外部入口，必须复用届时已经验证的画布命令与执行契约，并完成宿主一致性验证。

本轮产出是方案和清理结果，不是 Agent Flow 功能交付。下一项实现从 [C1](03-delivery.md) 开始，其验收必须直接发生在画布上。
