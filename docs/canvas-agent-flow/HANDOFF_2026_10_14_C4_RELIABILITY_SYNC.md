## 必须保留的产品边界

- 本地停止与远端已取消分开。官方 Ark 的 DELETE 会根据状态取消排队或删除已完成记录，前置 GET 无法关闭状态竞争；本包不自动调用该混合删除接口。只有可信同任务查询明确 cancelled 才登记远端取消，404/断网/未知协议不当作取消或生成失败。
- 同步 Agent 当前无可信持久异步任务身份；不能因 GLM 名称相同就套用其他网关的查询/取消 API，不能宣称同步 Agent 已支持远端撤回。
- trusted control 限官方 Ark 白名单。MiniMax/任意中转/无远端 ID/旧身份缺失保持 unknown。未知结果不自动重放、不无证据释放计费占用。
- reserved 或未提交回执的字节不构成完成证明；明确重试可以重新下载原成果，但不新建计费任务。prepared/committed 串行重开恢复已验证无网络/无重复下载，只有一个媒体身份。
- 本批保证同进程合并与串行重启，**未验证多个进程同时核对/物化或争抢遗留锁**。不能据固定 ID 或 30 秒保护期宣称跨进程排他已完成。

## 下一步唯一优先路径

**多进程恢复竞争与遗留锁争抢。** 先定义一条可演示路径：同一原任务被两个独立进程同时核对/物化，只有一个进程获得写入权，另一进程读取既有回执；强杀持有者后可安全接管，活进程不能被抢占。

1. 明确项目锁与成果物化锁的持有者身份、排他获取、释放及异常接管协议；避免双恢复者同时删除旧锁或同时截断同一阶段文件。
2. 在受控完整输入和固定 mediaId 下接公共任务路径，不能引入自动生成重试或未知结果强制释放。
3. 验收并发获取、迟到旧写者、强杀接管、PID/身份不确定、重复媒体登记、停止期间接管与冲突不覆盖；新增路径同时做诊断配对/脱敏和旧项目回归。
4. 之后再接有专用/原子取消语义的供应商，补远端查询/撤回真实证据；最后 C4 组合故障与桌面打包发布验收。

继续未覆盖：物理掉电/fsync 耐久性、磁盘损坏修复/持续监测、长期故障组合、真实视频解码/供应商计费/撤回、媒体/并行 Agent、任意节点建图、主控 Skill 和独立状态机输出。同步源码不能代替上述验收。
