### R09 供应商撤回边界（2026-10-16）

火山 Ark 官方 [取消或删除视频生成任务](https://docs.volcengine.com/docs/ark/cancel-or-delete-video-generation-tasks-api) 说明：DELETE 在 `queued` 时取消排队，`running` 不支持；`succeeded`、`failed`、`expired` 会删除任务记录。现有本机停止会先持久化停止意图，再用官方 GET 核对任务事实，不向非官方兼容端点发送控制请求，也不会在状态不明时重投。

单纯 GET 得到 `queued` 后再 DELETE 仍有竞态：上游可能在两次请求间转为 succeeded，令 DELETE 删除刚完成任务的查询记录。因此在没有供应商提供状态条件写入或等价原子取消协议前，不能把“本机已停止”升级为“远端已撤回”。仍需供应商协议/真实账户验收；当前只记录此边界，不宣称远端取消已支持。
