# C1 控制关系与状态转换交付

日期：2026-10-12；基线 93b0845。范围是可编辑的流程声明，执行仍待 C2/C3，不能把配置或虚线视为任务已执行。

## 画布用户路径

创建一个主控 Agent、两个专业 Agent、AI 审核和状态机。Agent 的职责与参与方式分别保存，专业 Agent 各自保存目标和预算。点击配置节点后，通过名称/类型选择处理范围；审核选择实际已连接的输出来源、修订负责人和待放行节点；状态机选择观察对象，并编辑初始阶段、阶段列表、起始阶段/事件/目标阶段。

示例声明：draft → submitted → working；working → review_passed → completed。同一阶段、同一事件只能有一个目标；删除仍被转换引用的阶段或使用不合法标识时，保存被阻止，原配置保留，用户可以修正或删除该转换。当前只声明转换，不实际推进任务状态。

保存后画布显示带标签、箭头的虚线：允许处理、观察状态、审核放行、反馈返工。点击标签打开所属节点设置，数据线的捕获监听不会抢走控制标签的点击。虚线随节点移动、分组页面坐标和相机缩放重算；遮罩覆盖卡片与标题，标签避让卡片。连线锚点按相对布局选择：横向节点从相对的左右边出入，纵向节点从上下边出入，斜向/近邻布局取最短且不穿过卡片的边，箭头终点落在目标卡片外边缘；重叠卡片固定从共同外侧绕行，避免缩放时锚点边翻转。几何计算集中在 `agent-flow-relation-geometry.ts`，不读取或修改关系配置、授权范围和数据 DAG。虚线不增加 tldraw arrow、binding 或数据 edges。

目标被删除后，保存的引用不静默清除或重新指向其他节点；卡片/设置提示失效，失效关系不画到错误位置，用户可以在目标选择器取消引用。审核对象必须来自真实的数据连接和已声明输出端口；清掉数据边后，原对象选择也会提示需要修正。

状态机卡片显示声明的初始阶段与未接执行提示。可见性验收补充：公共外壳会隐藏旧 small 提示，因此该必要状态改用明确内容呈现，并加入真实浏览器可见性断言。独立目标、角色、参与方式、范围、转换及关系保留在同一文档快照与 graph.params.config 中。

## 单一来源与协议

处理范围从 agent.allowedNodeIds 派生 controls；放行范围从 review.gatedNodeIds 派生 review-gate；rejectPolicy=rework 时，从 responsibleNodeId 派生 rework。观察关系保存在 config.relations。已有其他关系记录保留，但必须与所属节点/范围一致，可在设置中移除。相同语义关系只呈现一次；重复 relationId、伪造来源、范围外控制、自指和失效目标均校验。固定来源选择不是已提交资产版本，版本 pinning 归 C2。

共享校验器 declarations.ts 只读取声明，返回关系视图与问题，不变更业务图、不授予工具能力。AgentFlowRelationLayer 是同一画布上的只读投影；没有第二个可编辑流程、没有独立保存的关系图。节点类型、端口与 contractVersion=1 保持兼容。
