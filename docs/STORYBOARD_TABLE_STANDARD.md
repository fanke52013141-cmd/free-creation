# 分镜板表格特殊规范

分镜板以 JSON 为数据源，以表格展示；不是普通媒体或表单节点。本规则优先于普通节点的尺寸上限。

- 默认尺寸 960 × 420px。宽高无产品上限，可自由拖动缩放手柄；分组缩放仍只移动节点，不改变子节点尺寸。
- 自动模式按列数和实际行高展开，完整显示单元格内容。手动调整后保留用户宽高，不被内容自动覆盖；标题旁“恢复内容自适应”恢复分镜板宽高自适应。
- 自动列宽默认 220px，正文 13px；内容换行，行高随内容增长，无单元格截断。手动缩小时保留横纵滚动能力，滚动条始终隐藏。
- JSON 的 shots 数组中每个对象是一行，各对象字段的并集生成列；id 保留用于稳定关联，不作为内容列显示。
- 标题可以通过 titles 对象定义多个键值对，例如 `"titles":{"scene":"画面","dialogue":"台词","duration":"时长"}`。键对应真实数据字段；标题只影响呈现，不改变执行器或下游字段名。未定义标题时使用常见字段中文名或原始键名。
- 接受 `{ "titles": {...}, "shots": [...] }` 和镜头数组。缺失的标准镜头字段按已有协议补齐，自定义字段保留。编辑、运行和保存均保留 titles。
- 端口含义、连接方法、可复制 JSON 示例及输出说明放在“输入输出”弹窗，表格不重复显示内部端口介绍。

数据处理、JSON、结构数据、循环及分镜板的输入输出弹窗必须提供输入示例、设置与连接、预期输出、类型限制和失败条件；示例必须与实际执行器保持一致。
