# JSON、数据处理、数据结构用法

可导入案例：[json-processing.canvasflow](./json-processing.canvasflow)。在画布导入菜单选择此文件，会创建独立示例项目。

案例有四个节点，按从左到右运行，不调用模型或付费接口。

1. JSON 保存原始对象：`{"description":"人物走进书房，打开一卷古书","duration":5}`。它负责解析和输出数据。
2. 数据处理选择“提取字段”，路径填写 `description`，得到 `人物走进书房，打开一卷古书`。数组支持 `0.description` 等下标路径。
3. 另一个数据处理选择“字符串模板”，填写 `电影镜头：{{value}}`，得到 `电影镜头：人物走进书房，打开一卷古书`。
4. 数据结构选择“场景设定”，填写 `{"id":"scene01","name":"古书房","description":"{{text}}"}`，把上一步文本接到文本输入。运行后替换占位符并检查场景字段，输出完整场景对象。

区别：JSON 保存已有数据；数据处理取字段或转换文本；数据结构按明确的字段约束组织并校验数据。

字段提取只接收 JSON。固定值类型为“任意、对象、数组”均可以产生 JSON，不限于“任意”；文本及媒体值可通过字符串模板处理。音色 ID 属于音色档案里的字段，与朗读文本使用不同输入端口。
