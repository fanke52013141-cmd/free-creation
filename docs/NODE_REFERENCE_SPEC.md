# 节点引用呈现规范

版本：1.0 · 2026-10-05 · 强制规范；公共组件及视频专用引用已迁移，验收边界见 §5。

本规范与 [节点输入输出契约](../NODE_CONTRACT_SPEC.md) 配套：契约决定接收什么数据，本规范决定如何展示已接收的数据。引用布局与预览发生冲突时，以本文为准；取代 UI 规范旧版“每条连线一行”“多行引用继续增高”的要求。

## 1. 引用区域

**整个引用区域默认只显示一排；每条引用的文字也只显示一行。完整内容通过悬浮详情查看。**

- 位于节点正文最顶部，在配置、输入框和结果之前；无实际引用值时不渲染、不占位，不显示“未连线”、端口 ID 或输入输出说明。
- 只读取真实连线对应的输出投影。固定配置不是引用；有连线但尚无输出值时不制造内容。`0`、`false`、空字符串和空集合是有效值，不能误判为未连接；空字符串显示“空文本”。
- AI 处理保持只展示输出；裁剪、拆分等已有主素材预览的节点不重复展示同一素材。专用输入面若需要引用摘要，也遵循本文尺寸与详情规则。
- 引用只负责识别与查看；不增加“配置引用”等冗余按钮，不改变节点业务操作。

## 2. 尺寸与多项排列

以下均为画布 100% 时的 CSS px，统一进入公共样式令牌。

| 项目 | 规则 |
| --- | --- |
| 位置 | 正文顶部，沿用正文顶部及左右 12px 内边距，不重复叠加 |
| 引用区和每项高度 | 36px，图标、文字垂直居中 |
| 项间距 | 6px |
| 与下方正文间距 | 8px；引用区不存在时为 0 |
| 普通类型图标 | 16×16px，复用现有线性图标 |
| 图片、视频缩略图 | 48×36px，保持比例完整显示，不拉伸 |
| 文字引用 | 左右内边距 8px，内部间距 6px；单项填满可用宽度，多项每项 80–200px，超出省略 |
| 更多入口 | 高 36px，最小宽 36px，显示 `+N`，按位数自适应 |
| 背景 | 不透明中性底色和统一边框，身份色只用于小图标等强调元素 |

按目标端口声明顺序排列，同一端口按契约输入顺序排列，不因标题、运行状态或内容长度重新排序。按实际可用宽度容纳完整条目，先为 `+N` 留空间；放不下的条目计入 N。极窄空间优先保留更多入口。

不换行、不产生横向滚动条、不通过“展开”在卡片里新增引用行。悬停或点击 `+N` 查看剩余条目列表；列表中每项可查看完整详情，顺序与实际输入一致。折叠只是视觉行为，不截断执行器收到的集合。

新增引用时，自动高度在无引用正文需求上增加 **36+8=44px**，再向上取 260/320/380/440 档，最高 440px。默认 260px 因第一条引用升到 320px；从一条增加到多条不继续增高。不能缩小输入框抵消这 44px。移除全部引用后允许回落，手动高度保持用户选择。主预览承载素材而没有独立引用行时不额外计高。

## 3. 各类型的统一格式

文字项采用“类型图标 · 输入角色 · 内容摘要”；角色使用目标端口的业务名称，例如“朗读文本”“音色”，不显示 `in-text` 等技术 ID。媒体项使用缩略图，角色与来源放入详情和无障碍名称。同一角色有多项时，各项详情仍须能识别来源。

| 输入类型 | 一排内显示 | 悬浮完整详情 |
| --- | --- | --- |
| 文本 | 角色 + 正文摘要，换行仅在摘要中折为空格 | 完整原文、保留换行、可选择复制 |
| Markdown | 角色 + 可读摘要 | 安全渲染标题、列表、粗体、代码等；可复制原文，禁用原始 HTML 执行 |
| 数字、布尔值 | 角色 + 实际值，如 `0`、`false` | 完整值与数据类型 |
| JSON 对象、数组 | 角色 + 紧凑 JSON 摘要；空值明确为 `{}`、`[]` | 格式化完整 JSON，可滚动和复制，不把摘要当成真实输出 |
| 音色档案 | 音色图标 + “音色” + `voice_id`，始终单行省略 | 完整音色 ID、供应商及档案已有字段；支持复制 ID |
| 图片 | 完整图片缩略图 | 按比例显示完整图片和已有尺寸信息；点击进入完整预览 |
| 视频 | 首帧缩略图 + 播放标识 | 放大首帧和已有时长信息；不自动播放，点击进入播放器 |
| 音频 | 音频图标 + 角色 + 名称 | 完整名称、已有时长，提供明确的播放/暂停操作，不自动播放 |
| 文件 | 文件图标 + 角色 + 文件名 | 完整文件名、已知类型和大小；已有提取文本可查看，不因悬停重新解析文件 |
| 任意类型 | 按实际解析出的值类型使用以上格式 | 展示真实类型和内容，不把“任意”当作内容 |

音色必须由端口 Schema/契约标识识别；不能因为普通文本长得像 ID、上游标题含“音色”或任意 JSON 恰有同名字段，就改变连接与执行语义。音色档案和朗读文本继续使用各自契约入口。

所有详情统一含输入角色、来源节点名称和业务输出名称；不把这些元信息全部挤到摘要中。未知时长、尺寸或文件大小直接省略，不伪造；媒体不可读取时显示紧凑错误标识，详情说明原因，不用另一张素材代替。

## 4. 悬浮详情交互

- 悬停 300ms 或键盘聚焦打开详情；触控及更多列表支持点击打开。Esc、点击外部关闭；离开触发项和详情后延迟 150ms 关闭，允许移入详情阅读、滚动、复制。
- 使用公共 Portal 浮层，不能被节点滚动容器裁切。高于画布节点，低于任务状态浮层及模态弹窗；自动避让视口边缘，保留 8px 安全边距。
- 最大宽度为 `min(480px, 视口宽度 - 16px)`，最大高度为 `min(420px, 视口高度 - 16px)`；长内容在详情内滚动，正文不截断。详情滚轮和播放操作不触发画布缩放、拖动或节点运行。
- 深浅主题均使用不透明背景；不扩大节点、不改变连线位置。不要仅使用浏览器原生 `title` 代替完整详情。
- 预览按需加载并复用已有资产缓存；视频仅取首帧，不自动播放、不预加载完整视频集合。悬停不触发模型调用、保存、输入值修改或付费任务。
- 展示由契约读取器提供的当前有效值，不自行回退到其他端口或旧结果；输入未就绪和失败信息仍由端口/运行状态承载。敏感配置不进入引用，预览内容不写诊断日志。

## 5. 实施与验收

统一由公共引用组件和公共详情浮层负责，不允许节点自行复制一套布局。业务节点仅声明角色、契约与是否已有主预览；复用既有输入读取、媒体预览及输出投影，不建立第二套输入解析机制。

2026-10-05 实施：全部节点复用的 `ConnectedInputPreview` 已改为按宽度单排布局、36px 高度、+N 详情列表及可进入的公共 Portal。文本/Markdown/JSON/音色与媒体按真实值展示，来源及业务端口名进入详情。视频生成移除独立引用条与重复音频/运动参考说明，纳入同一入口；AI 处理、裁剪、拆分继续使用已声明例外。媒体点击复用完整预览，悬停不自动播放。

更多列表先显示紧凑摘要，选择或悬停其中一项后读取完整详情，避免打开 +N 就加载全部媒体。当前 `MediaNodeValue` 没有文件大小和提取正文，详情只显示已有名称与 MIME；音视频时长、图片尺寸由预览元数据取得，不伪造。文件扩展元数据接入后仍沿用同一详情组件。

浏览器门禁 `scripts/test-browser-node-references.cjs` 使用真实连线验证十张图片单排折叠、第一条引用增高与删除回落、长文本全文滚动、移入详情、键盘关闭、三种缩放、JSON 的 0/false/空对象/空数组及音色 Schema；另验证安全 Markdown 渲染、视口避让、不透明主题和低于模态弹窗的层级。全量 `npm run verify` 通过：1496 项测试通过、1 项既有跳过，另有模型包 2 项测试及全部 28 节点布局、颜色、选中浏览器门禁。桌面包在独立临时数据目录启动并验证项目入口及菜单隐藏。未逐项模拟所有文件格式、音视频编解码器及触控设备，不能把公共布局验收当作所有媒体格式都已验证。

实施后必须逐项验证：

1. 无引用不占位；`0`、`false`、空文本和空 JSON 可识别；断线后立即移除。
2. 单项、多项、混合类型、超长中英文及多端口均只有一排；`+N` 数量和契约顺序准确，所有值仍参与执行。
3. 悬停、键盘、触控均可查看完整内容；复制、滚动及音频播放不误触画布；媒体保持比例且不自动播放。
4. 默认卡片第一条引用增高到 320px，多条不继续增高；删除回落、440px 上限和手动模式正确。
5. 深浅主题、75%/100%/150% 缩放、视口四角及任务弹层叠加正确；例外节点不重复预览。
6. 保存重开、撤销、输入端口绑定与执行结果不受摘要和折叠影响；节点修改通过仓库全量验证。
