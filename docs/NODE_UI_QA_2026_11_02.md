# 节点卡片 v1.5 实施与验收备注（2026-11-02）

> 本文记录本轮「节点卡片统一规范 v1.5」的落地内容、用户裁决口径与验证证据，供后续维护与回归对照。
> 规则正文见 [`NODE_UI_STANDARD.md`](./NODE_UI_STANDARD.md) §20；身份色应用边界见 [`NODE_COLOR_SPEC.md`](./NODE_COLOR_SPEC.md)。

## 1. 用户裁决口径

| 项 | 裁决 |
| --- | --- |
| 图标边界 | 口径 A：删除卡内区块标题图标、文字按钮图标与装饰图标；保留卡外标题栏图标、空态中心身份图标、纯图标功能控件（播放/暂停、缩放、删除等） |
| 区块标题分隔线 | 全部不画线，不加图标；只用 12px 间距分组 |
| 卡片/边框颜色 | 统一中性灰，不使用节点分类色；类型色只保留在端口、卡外标题栏、类型切角、空态身份图标、状态点 |
| 语音合成端口 | 默认一进一出；`in-voice` 不常驻，真实连接或拖线候选时展开 |
| 双按钮 | 语音克隆底部并排「上传/替换参考语音｜克隆音色」；语音合成保留单按钮「合成语音」 |

## 2. 代码改动摘要

- 公共层：新增中性灰令牌与卡片 1px 外框；`NodePrimaryButton` 只渲染文字并支持 `secondary` 变体；新增 `NodeSectionTitle`（纯文字标题）；卡内正文统一以中性灰覆盖节点分类色。
- 语音克隆：删除「也可从左侧连接音频；支持 mp3、m4a、wav，10 秒至 5 分钟」；输入 28px；正文次级按钮自适应宽度；底部双按钮；去掉私有卡面、渐变与标题图标。
- 语音合成：去掉分组子卡描边/渐变/下划线；上传参考音频改纯文字入口；删除 8 处标题图标；端口按需展开。
- 音色设计 / 人声分离：同步去标题图标与节点色描边。
- 端口：`graph.ts` 取消语音合成 `in-voice` 与音色设计 `out-json` 的强制 pin；端口可见性交回 `node-port-layout` 的“每侧一个代表类型”规则。
- 文档：`NODE_UI_STANDARD.md` 新增 §20；`NODE_COLOR_SPEC.md` 补应用边界。

## 4. 已知边界

- 浏览器颜色门禁 `scripts/test-browser-node-colors.cjs` 在浅色 `video-clay` 标题图标上报对比度 2.958（阈值 3）；该值与本轮卡片样式改动无关，属既有颜色令牌边界，需单独调色处理。
- 本轮只改呈现层，不涉及执行器、契约、数据流与持久化；日志影响按 `LOGGING_SPEC.md` 判定为“不涉及”。
- 桌面应用需重启后生效（启动器会按源码增量重建）。
