# 组合能力编辑优化发布备注（2026-11-11）

## 发布范围

本次发布聚焦“组合能力”的版本编辑与公开端口修正，不涉及模型供应商凭据、项目数据迁移或其它节点行为。

## 用户可见变化

1. **节点库组合卡片**
   - 显示组合名称、`v1.0`、输入/输出数量；
   - 操作：`编辑`、`新版本`、`版本`。

2. **编辑进入全屏组合画布**
   - 不再使用窄侧栏 + 节点流程条；
   - 独立 tldraw 画布，不触碰用户当前项目；
   - 顶部：返回、组合名/版本、添加文本/AI 处理/生图、保存并发布；
   - 选中节点复用现有节点设置面板（模型、系统提示词、参数等）；
   - 节点可拖动、框选、缩放；节点多时使用画布平移/缩放。

3. **公开端口默认推导修正**
   - 文本源节点 → 1 个文本输入；
   - 汇节点主输出 → 1 个公开输出（媒体优先）；
   - `文本 → AI 处理 → 生图` 默认 `1 输入 / 1 图片输出`；
   - 中间 AI 节点的 markdown/json 不再自动公开。

4. **版本规则**
   - 主版本整数：`1.0 / 2.0 / 3.0`；
   - 旧 `1.0.0` 兼容显示为 `1.0`；
   - 允许直接修改并覆盖同一主版本；
   - 版本历史可查看、载入旧版本；`新版本` 自动 +1。

5. **修复**
   - 组合 JSON 公开端口缺 schema 导致项目保存失败；
   - AI 处理节点在无文本模型时错误隐藏系统提示词/温度/最大输出。

## 数据兼容与迁移

- 已有组合 manifest 不会自动重算端口：
  - 打开组合 `版本` → `输入输出` → **按内部图重新推导** → 发布；
  - 或进入全屏画布后保存并发布，会自动重推导。
- 旧版本仍保留，可按主版本号发布新版本；同版本发布会覆盖该版本内容（用户裁决）。
- 未修改项目快照格式、数据库 schema（本轮只新增版本列表查询 IPC/Agent 操作）。

## 验证证据

- `test/composite-boundary.test.ts`：1 文本输入 / 1 图片输出；中间 markdown/json 不公开；
- `test/composite-build-manifest.test.ts`、`composite-manifest`、`composite-repo`、
  `composite-agent-access` 相关测试通过；
- `npm run typecheck:web`、`npm run build` 通过；
- `npm run guard:agent-parity` 三关全绿（新增 `composite.version.list` 已登记）；
- 应用以隔离数据目录启动验证窗口正常。

## 未验证 / 已知限制

1. 全屏编辑画布的“端口拖线”手势尚未在真实窗口逐步验收；当前复用 tldraw 默认箭头工具，若连线端口元数据不完整，需要接入主画布端口拖拽层。
2. 版本删除/引用保护未实现。
3. 旧 composite 实例升级到新版本入口未实现。
4. 真实人物设计链路（文本→AI→生图→公开图片→下游消费）未跑。
5. P3 持久等待/恢复、P5 画布 Agent 未完成。
