## 三、关键架构事实（接手必读）

1. **三入口一份实现**：CLI（`src/local-agent/index.ts`）与 MCP 工具目录由同一 Registry 自动生成；业务实现只有一份（main 服务 + renderer 权威宿主），没有外部专用执行器。
2. **权威宿主模型**：main 拥有存储/准入/账本；画布变更必须经桌面握手（`src/shared/agent-access/desktop.ts` 的 `graph-patch`/`read-graph`/`execute-nodes`/`cancel-run` 等动作）到 renderer 应用。外部输入不可携带路径（媒体只有 mediaId）。
3. **故障语义**：准入前校验失败=failed（整批不留半图）；准入后任何失败=unknown（OUTCOME_UNKNOWN，按确定 ID 与 graph.get 核对，幂等键重放原回执不重发）。
4. **门禁**：`npm run verify:agent-access`（登记/快照/影响哈希）、`node scripts/audit-business-actions.cjs`（动作分母）、typecheck、接入测试（当前 78+ 项）。契约快照 `docs/local-agent-access/generated/contracts.json`；Schema 变更必须 `--accept-contract-change` + 影响说明。
5. **授权门禁**：真实桌面启动需授权激活（`bootLicenseGate`）；桌面测试用 `scripts/test-license-electron.cjs` 同款协作激活（软件设备适配器 `CANVAS_LICENSE_ALLOW_SOFTWARE_DEVICE=1` 仅开发构建）。
6. **交付台账**：`docs/local-agent-access/17~21 号文档`（17 F0 基线、18 F1F2 画布、19 F3 执行、20 里程碑、21 F4/F5/F6 逐批）。
7. **运行环境**：ffmpeg 在本机 PATH 可用（8.1 essentials）；里程碑需要 `npm run build` 后运行（CLI 走 `out/main/local-agent.js`）。
8. **工作区并行修改**：授权/密钥库/发行版等未提交修改（license/security 等）属其他进行中工作，全部保留未动；`verify:agent-access` 的哈希声明只含本任务文件。
