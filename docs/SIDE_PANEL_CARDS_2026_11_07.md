# 2026-11-07 画布右侧资产面板卡片统一

## 背景

用户反馈：
1. 项目素材的三个高级筛选（来源/状态/时间）被竖排成三行；
2. 项目素材里的视频封面裂图；
3. 资源库（画布侧栏）的卡片样式与项目素材不一致，标题下应只有「时间 + 版本」；
4. 项目素材/资源库/节点库的搜索框出现"框里套框"；
5. 节点库应改成卡片样式、只显示标题、支持拖到画布、删除二次确认。

## 一、项目素材

- 三个高级筛选固定一行：`.assets-advanced-filters` 恒为 3 列，删除窄容器/窄屏的竖排覆盖；
  触发器改用短标签（来源/状态/时间，`data-trigger-label`），下拉项仍保留完整文字；
- 视频封面不再用 `<img>`（指向 mp4 必然裂图）：改为静音 `<video preload="metadata" src="…#t=0.1">`，
  与图片共用 `object-fit: cover`，保留播放角标；
- 卡片 meta 单行省略：`.asset-meta` 加 `nowrap + ellipsis`。

## 二、资源库（画布侧栏 picker）

- 卡片直接复用项目素材的 `.asset-card / .asset-thumb / .asset-info / .asset-name / .asset-meta`：
  封面（无封面用 layers 图标占位）+ 标题 + 「时间 · 版本（1.0/2.0）」；
- 搜索框改用与项目素材相同的 `.assets-search-row + .assets-search`，不再出现双层输入框；
- 删除改为硬删除并二次确认（与资源库页一致，调用 `library:delete`）；
- 点击/拖拽到画布逻辑不变。

## 三、节点库

- 改为与项目素材一致的卡片网格（`.assets-grid + .asset-card`）：只有标题，不再显示节点数/连线数/时间；
- 卡片支持点击（放到视口中心）和拖拽（落到光标处）：`addNodeLibraryEntry` 增加可选 `dropScreen`，
  用 `editor.screenToPage` 计算落点；
- 删除保留二次确认；搜索框同样使用项目素材的样式。

## 四、实现要点

- 复用公共样式而不是复制：`asset-card` 系列只维护一份，资源库 picker/节点库直接套用；
- 侧栏内滚动收口：节点库卡片网格随面板整体滚动，避免嵌套滚动条；
- 资源库 picker 去掉额外 12px 内边距，与项目素材对齐（父级 `side-panel-body` 已有 16px）。

## 日志影响

- 纯 UI/交互与呈现层调整（卡片结构、筛选布局、拖拽落点、删除确认）；
- 资源库删除复用既有 `library:delete` 与其日志；不新增日志字段、不改 Schema。

## 验证

- 浏览器截图核对了：项目素材筛选一行、视频封面正常、资源库/节点库卡片统一、搜索框单层；
- Playwright 实测节点库卡片拖到画布：节点数 0 → 1；
- 窄侧栏（约 193px）下卡片与筛选仍可用，meta 省略号；更宽的真实侧栏会完整显示。

## 未覆盖边界

- 未在真实桌面窗口逐项截图三种侧栏宽度；
- 资源库 picker 的删除流程只做了代码路径复用，未跑真实 SQLite 删除。
