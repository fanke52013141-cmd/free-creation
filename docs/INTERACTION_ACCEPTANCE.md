# 节点交互验收（本地桌面版）

本清单只覆盖单机本地运行。任何操作都必须保持节点的输入/输出端口、Schema 校验和统一执行器不变；不得把运行结果写回用户配置。

## 自动化门槛

在仓库根目录运行：

```powershell
npm run lint
npm run typecheck
npm test
node_modules\.bin\electron-vite.cmd build
```

应全部通过。重点测试包括：节点契约矩阵、Schema 连接矩阵、显式目标端口的新建菜单、执行状态文案、bundle 导入媒体重映射与事务回滚。

## 1. 公共节点体验

1. 从任意输出端口拖到空白画布。
2. 验证菜单只列出可接收该输出的节点；多输入节点必须展示目标输入名称与类型。
3. 选择一个条目后，验证新节点已创建且连到了菜单显示的那个端口。
4. 对 JSON 输出重复操作，验证不兼容 Schema 的专用输入不出现；`json.any@1` 仍可作为通用适配端口。
5. 选中任意节点，确认悬浮栏显示中文状态、复制 ID 和“查看详情”；信息按钮打开对应契约/对话/导演台面板。

## 2. 基础节点

1. 文本节点双击编辑、Esc 或失焦提交；确认内容保存在 `text`，卡片显示字数与编辑提示。
2. 输入 `/九宫格 主题`，确认生成按钮创建独立的生图节点，配置写入 `config` 而非 `text`。
3. 图片节点导入、替换、预览；预览中验证定位、复制路径、系统打开均只使用本地媒体 API。
4. JSON 节点分别输入合法对象、数组、`null` 与非法 JSON；确认有效/错误状态、字段/条目预览、格式化和复制行为正确。

## 3. 媒体生成节点

1. 生图节点连接参考图与文本，确认参考图提示可见；运行后，结果卡显示模型/生成时间，重新生成只清理媒体结果。
2. 视频节点连接首帧图和文本，确认首帧提示及缩略图出现；运行后可预览视频、显示生成来源，重新生成返回配置态。
3. 音频节点分别测试上传与合成。合成模式确认字数、音色、格式和“上游文本会合并”的提示；生成/替换后播放器状态应复位。

## 4. 工作流节点

1. 处理节点分别测试“已连线”和“固定值”状态；连线存在时固定值输入不应参与实际输入。
2. AI 处理节点切换文本、Markdown、JSON 输出；JSON 模式必须可见版本化 Schema，结果只来自 `meta.nodeResult`。
3. 代码节点增加两个参数，再故意制造归一化后的同名参数；确认冲突会明确提示，且动态端口不会静默复用。
4. 循环节点设置限数、失败策略与重试，运行后确认结果统计来自 `meta.nodeResult`，配置编辑不会覆盖结果。
5. 导演台确认只有“发布”后的帧/视频/相机参数可供下游使用；该项为后续 3D 增量，不作为普通节点完成度门槛。

## 5. 桌面与性能冒烟

1. 新建项目，连续创建 100 个节点和至少 150 条合法连线；拖拽、缩放、框选、端口高亮、菜单开关不应明显卡顿或错误连线。
2. 保存、关闭并重新打开项目；确认配置、用户文本、执行结果与本地媒体引用均恢复，且媒体仍可预览。
3. 导出 bundle 后导入为新项目；验证所有媒体引用都指向新项目目录，原项目不被修改。
4. 在无网络、无登录状态下启动应用；画布、项目、图片/音频本地导入和已配置的节点编辑均可用。模型调用可因未配置供应商而提示，但不得阻塞其他本地操作。
