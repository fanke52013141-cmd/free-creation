# 画布性能基准（P1）

本项目的性能验收分为两层：可重复的**数据层基准**与真实 Electron 的**交互冒烟**。两者不能互相替代。

## 1. 数据层基准

运行：

```powershell
pnpm benchmark:canvas
```

脚本会在系统临时目录构造 100、500、1000 节点的合法项目，分别测量：项目构造、JSON 序列化、JSON 解析与 bundle 写入耗时。临时 bundle 在命令结束时自动删除。

若需要把基准项目导入桌面版做人工测试：

```powershell
pnpm benchmark:canvas -- --out "$env:TEMP\canvas-studio-benchmarks"
```

输出目录会包含三个 `.canvasbundle`；在项目列表中导入其中一个即可。完成后手动删除该临时目录，绝不提交这些产物。

脚本只报告本机结果，不设跨机器的固定毫秒阈值。机器型号、显卡、缩放比例和 Electron 版本均会影响数字；趋势回归才是它的用途。

## 2. 桌面交互基准

对每个 100 / 500 / 1000 节点项目，记录以下结果：

| 项目      | 检查                           | 通过标准                             |
| --------- | ------------------------------ | ------------------------------------ |
| 首次打开  | 画布可恢复、无白屏或节点丢失   | 可操作，控制台无恢复错误             |
| 拖动      | 连续拖动一个节点和一个分组     | 没有明显输入延迟、错误连线或掉帧卡死 |
| 缩放/框选 | 鼠标滚轮缩放、框选 20 个节点   | 不错选、不触发错误菜单               |
| 连线      | 在空白处拉出连线并新建目标节点 | 目标端口明确，连线端点正确           |
| 保存重开  | 保存、关闭、重新打开           | 配置、文本、运行结果和媒体引用仍在   |

详细的节点交互、媒体和导入导出检查见 [INTERACTION_ACCEPTANCE.md](./INTERACTION_ACCEPTANCE.md)。

## 3. 固定演示项目

```powershell
pnpm build:demo
```

这会生成 `resources/demo/canvas-studio-demo.canvasbundle`。它是功能回归素材，而不是性能夹具，覆盖两条端口明确的链路：

```text
文本 → AI 处理 → 分镜 → 导演台
图片资产 / 文本 → 生图 → 视频
```

导入该包后应确认：所有八个节点存在、七条连线端口正确、图片媒体被重映射为新项目路径，且未携带 API Key 或供应商配置。
