# Infinite Atelier 借鉴边界

参考仓库：[GuiYi-Xi/infinite-atelier](https://github.com/GuiYi-Xi/infinite-atelier)。

| 参考对象      | 我们采用的内容                           | 必须保持的差异                                           |
| ------------- | ---------------------------------------- | -------------------------------------------------------- |
| 节点卡片      | 参数摘要、状态、悬浮操作、选中与关联高亮 | 所有输入输出仍是明确 portId + Schema                     |
| 连线末端菜单  | 在空白处快速创建节点                     | 菜单只显示兼容类型和 Schema 的节点，创建后连接具体端口   |
| 多媒体结果    | 折叠结果、预览和单项操作                 | 每个结果必须进入 MediaAsset 并有正式输出语义             |
| 资产/历史面板 | 检索、筛选、定位画布节点                 | 资产来源来自运行记录，不按节点类型猜测                   |
| 导演台        | 层级、资源、镜头和时间线概念             | 后置开发；不用 iframe/localStorage；维持手动发布端口协议 |

禁止采用：无端口连线、扫描上游节点类型推断输入、巨型 Config 节点、把 Group 当业务节点、
浏览器本地存储作为项目库，以及组件内直接执行模型调用。
