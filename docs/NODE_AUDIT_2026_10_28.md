## 需要处理的问题

1. **视频截取：快速复制的仅画面可能生成空视频。** 工作台选择 0.5–1.5 秒、仅画面、快速复制，生成资产卡后 `ffprobe` 未检测到任何流；真实 FFmpeg 回归也重现。平衡质量的相同区间正确。证据 `fast-workbench.json`，实现 `src/main/media/video-transform.ts` 的快速复制分支。
2. **P 图选择即梦 5.0 失败。** 原图连线与配置之后真实执行返回 `Invalid URL`，没有图片；重开工作台确认即梦模型显示在节点中。代码的图片生成有即梦 CLI 分支，而编辑路径落入通用 HTTP 分支。证据 `image-live.json`、`edit-dreamina-visible.png`，入口 `src/main/gateway/image.ts` 的 `generateImageEditToAsset`。
3. **音色设计的档案连线难以到达。** 音色设计成功后自动创建试听卡，空闲时设计节点仅显示音频输出、语音合成仅显示文本输入；直接拖拽音色档案测试因两端目标端口不可见而中断。隔离项目移除试听卡后，档案连线和真实合成成功。现行 `docs/NODE_UI_STANDARD.md` §19 明确要求音色设计默认连接点为音色档案。证据 `design-live.json`、`design-resume.json`；端口布局见 `src/renderer/src/canvas/node-port-layout.ts`。这证明该拖拽路径受阻，其他可能的入口尚需排查。
4. **音频参考过短时的错误信息需要改善。** 1 秒音频由即梦 CLI 拒绝，错误包含本地路径；3 秒参考音频的画布真实生成成功。应在提交前告知时长约束并避免暴露路径。
5. **对话生图部分模型受限。** 即梦 5.0 被对话生图的 low 质量能力检查拒绝，虽然普通生图节点可使用。TOAPIS 先前两次返回 HTTP 503，后续真实重试成功。包括先用真实文本模型对话，再切换生图：先要求记住戴红帽的白猫，生图消息只提“根据刚才确定的主角”，生成的图片确实是红帽白猫；预览、下载文件字节一致和进程重启后恢复通过（chat-dialog-real-to-image/results.json）。
6. **状态机的多分支事件无法直接选择。** 在同一初始阶段配置 `accept` 和 `reject` 两条合法转换并运行初始化后，卡片文字列出两个可提交事件，但只显示“提交事件 accept”按钮。点击首个事件后可以成功迁移并在重载后保留。代码仅使用 `legalEvents[0]`，当前人工提交入口未找到选择其他事件的控件。证据 `D:/tmp/canvas-node-audit/state-branches-transition.json`；此结论针对手动状态机交互，不代表 Agent 驱动事件全部不可用。
7. **Agent 模型验证在重启后失效。** 隔离配置中对 `glm-5.3-flash` 真实验证成功，目录立即显示 verified；关闭重启后显示 unverified（`agent-validation-restart.json`）。代码中旧供应商启动同步总是传入已有密钥，模型目录将非空密钥视为连接变化并递增修订，导致旧验证不再匹配。上次隔离 Agent 验收的超时不是模型执行超时：节点因未验证而拒绝启动，但旧测试脚本继续等待任务，最终报 `AGENT_TASK_TIMEOUT`。
8. **抽帧工作台的尾帧预设失败。** 4 秒、25 fps 的真实视频，在工作台点击“尾帧”后，节点实际保存为 `custom, timeMs=3999`；选择 PNG 执行失败，提示未生成有效文件，选择 JPG 也失败。点击首帧同样会保存为 `custom, timeMs=0`，但该样本首帧 PNG 成功；手动指定 2 秒的 PNG 和 JPG 均成功。原因线索：视频 seek 完成回调将预设改写为自定义位置；需修复后在画布重验尾帧。证据 `frames-workbench.json`、`frames-variants.json` 及隔离项目快照。测试脚本中按预设模式匹配配置和固定期待三张图片的派生失败不作为独立产品缺陷。
