五轴自查：正确性——校验使用实际输入且与执行器一致，字段模式不被静默替换；简洁性——共享解析函数，卡片特有预检放在独立 helper；架构——保留注册契约和公共执行/输出路径，没有组件直调模型；安全——免费节点矩阵不读取用户真实库/密钥，系统选择器夹具只在隔离 Electron 测试中替换并在 finally 恢复，桌面 CSP 未放宽；性能——预检只对数据处理启用，取景只在用户整理时调整，不在每次渲染重新布局。新增脚本/浏览器入口的 lint 与 typecheck 已通过；最终五轴审查与完整门禁已完成；详见 verify-compact-final.log（1508 项单测、2 项模型包测试、28 节点门禁、两种视口与两档缩放比例检查及生产构建通过）。

真实模型阶段按明确授权只读读取了配置，凭据留在受当前 Windows 用户保护的本地副本，不进入报告、shell 参数或压缩包。模型验收器只记录长度、终止原因及产物摘要；原输入/输出正文不新增到诊断。尺寸控件复用现有 `onResize` 与快照保存，不引入业务执行路径。
