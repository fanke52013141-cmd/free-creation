## 1. 这一批到底改了什么（用户可感知）

### 1.1 首页
- 项目卡片悬浮光大幅减弱（中心 8%、边缘光 26%、上抬 2px），避免首页过亮。

### 1.2 资源库
- 顶栏统一：只保留「资源库」标题在左；导出、新建分类、编辑分类（下拉选择）、新建资源
  收进顶栏；右上角保留固定返回图标，解决“进资源库回不去”。
- 卡片：16:9 封面、标题 + 版本（`1.0 / 2.0 / 3.0`，不再 v1）、单行说明；去掉“组合资产/
  分类”角标和组件数。
- 默认封面：魔方改为**星光**（Stitch 参考稿落地的 SVG）。
- 侧栏资源库/节点库：卡片样式与「项目素材」统一；视频封面不再裂图；搜索框去掉“框中框”；
  节点库只显示标题、支持点击/拖拽到画布、删除二次确认。
- 详情抽屉：去掉“放入项目”、勾选框、最新/查看中标签、迭代次数等冗余提示；编辑语义改为
  「编辑资源 / 保存为新版本」「以 vN 为基础新建版本」；**取消归档，改为二次确认后彻底删除**。
- 新建/编辑分类弹窗：去掉展示样式/封面/排列/节点名称模板等蓝图设置，只保留基本信息与节点槽位。
- 删除：新增 `library:delete` 硬删除（清理版本/组件/引用/文件），不再用归档。

### 1.3 通用控件
- 所有下拉框关闭态强制单行 + 省略号，悬浮 `title` 显示完整内容（修复长模型名换行）。
- 引用候选菜单（输入 `@`）改为单行列表，长标题省略、悬浮看全文。

### 1.4 画布/节点
- 生成中的遮罩不再让正文可点击；底部操作条生成中禁用。
- 星辰加载动效粒子更柔，不再像明显圆点。
- 视频节点：预览固定 16:9 无大黑边；底部只保留 替换/视频截取/抽帧 三个等宽按钮，
  删除复制节点；视频工作台改双栏、不整体滚动，修复抽帧 tab 切换与关闭按钮失效。
- **Vidu Q3 能力修复**：Q3 补齐文生/首帧/首尾帧/参考四种模式，Q4 仍只开放参考；
  按官方 vidu-cli 文档映射任务类型与时长。
- **视频后台续跑**：退出项目/返回首页后主进程继续轮询；重新进入项目按持久化 taskId
  自动接回任务，不再误报「应用关闭或重启中断」。旧包遗留的 cancelled 记录无法追溯，
  需重跑；新发起的都正常。

### 1.5 轨道线（timeline）
- 框选穿越轨道线时选框消失：去掉强占编辑态的 `setEditingShape`（Delete 改由捕获阶段拦截）。
- 音频轨全屏播放：新增 `<audio>` 播放与音频占位；播放/暂停/seek/音量与视频一致。
- 连接素材后节点拖不动：去掉引用素材条整行的 blanket `data-node-pointer="control"`。
- 吸附修复：音频也参与吸附；落点压到已有片段 → 直接接到该片段末尾；空白区吸到最近合法边缘。
- **同轨不再允许任何重叠**：图片/视频/音频一视同仁；需要叠音请放另一条轨道。
- 旧项目里已有的同轨重叠片段不会自动拆开，但移动/裁剪时会要求避让。

### 1.6 组合/分组
- 折叠/展开图标改为两张卡片堆叠/并排；去掉 hover 背景块，按钮保留固定淡底。
- 折叠后标题显示原分组名（灰色、可双击重命名），不再显示「可复用」。
- 堆叠总错位固定 20px，N 个节点在这段距离内插卡，不再越叠越宽。
- 分组/折叠容器补深色底；多选工具条「组合 / 取消组合」加淡底；文案从“打组”统一为“组合”。

## 2. 打包前检查清单

在仓库 `source` 目录执行：

```bash
git fetch origin
git status
git log -1 --oneline          # 确认 HEAD 不早于 e8f6290，推荐 checkout packaging-2026-11-08
npm ci                        # 或按仓库约定安装依赖
npm run typecheck
npm run lint
npm run build
```

> **随包二进制（必须准备）**：`electron-builder.yml` 通过 `extraResources` 打包
> `build/bin/dreamina.exe`、`ffmpeg.exe`、`ffprobe.exe`。这些二进制被 `.gitignore` 忽略，
> **不在仓库里**，打包机必须提前从本机/内部制品库复制到 `build/bin/`，否则安装包会缺少
> 即梦 CLI 与 FFmpeg，视频截取/抽帧/轨道线合成会失败。打包前执行：
>
> ```bash
> ls build/bin/dreamina.exe build/bin/ffmpeg.exe build/bin/ffprobe.exe
> ```
>
> 缺少时不要开始 electron-builder。

建议再跑：

```bash
node scripts/run-vitest.cjs run   # 全量单测（约 20s，本批收尾时 269 文件 / 3105 项通过）
npm run verify:agent-access       # 受保护源码门禁
```

打包命令（按你们现有分发流程选一个）：

```bash
npm run build:win                 # Windows 安装包
npm run build:distribution        # 分发构建脚本
npm run build:unpack              # 仅解包目录，便于冒烟
```

构建产物以 electron-builder 输出目录为准（`dist/` 或脚本指定目录）；打包前请确认没有
`out/`、`dist/` 旧产物混入。

## 3. 打包后手动冒烟（按优先级）

1. **视频后台续跑**：项目里发起视频生成 → 返回首页 → 重新进入项目。
   - 预期：提示「已接回 N 个后台视频任务」，节点保持运行中，完成后自动写回结果；
   - 旧版本遗留的运行会提示「未找到可恢复的任务号…」，属预期。
2. **资源库**：首页→资源库，返回按钮在顶栏和右上角都可用；新建资源/分类、编辑分类下拉、
   删除二次确认；卡片有星光封面、版本 1.0。
3. **侧栏**：项目素材筛选一行；视频缩略图不裂；资源库/节点库卡片样式一致；节点库卡片可拖到画布。
4. **下拉框**：节点里选长模型名，触发器单行省略，悬浮显示完整名称。
5. **轨道线**：拖音频到轨道→全屏→播放有声音；连接素材后节点可拖动；开吸附后拖入已有内容的轨道
   会接到末尾；同轨无法再叠放图片+音频。
6. **生成中**：图片节点生成时点正文/模型下拉，不应能打开。
7. **Vidu Q3**：模型选择 Q3 后应能选到 文生/首帧/首尾帧/参考 模式（需配置 Vidu Token 才可实跑）。

## 4. 兼容性与注意事项

- **无数据库迁移**：本批没有新增表/字段；旧项目、旧资源库数据可直接打开。
- 资源库的“归档”已改为硬删除；旧版本残留的归档数据不会自动迁移，仍留在数据库但不再有入口，
  如需清理可后续单独处理。
- 视频任务号存在节点 `props.config.taskId`；旧版本发起的运行没有该字段，无法自动恢复，需重跑。
- 同轨不重叠是行为变更：旧项目已有重叠片段仍能打开和显示，但再次移动/裁剪会被要求避让。
- 本批涉及生成中遮罩、视频工作台、轨道线等交互，建议保留旧版安装包以便回滚。
