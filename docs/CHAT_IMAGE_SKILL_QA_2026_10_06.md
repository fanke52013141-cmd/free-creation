# 对话生图交付与验收（2026-10-06）

## 已实现

AI 对话增加内置生图技能和显式“生图”发送方式。默认 1K、可选 4K、质量固定最低档 low。生成图片保存为项目资产，显示在助手消息内，支持大图预览、Escape 返回和选择目录下载。对话 TXT 输出保持原契约。设置及使用边界见 [功能规范](./CHAT_IMAGE_SKILL_SPEC.md)。

## 五轴代码审查

1. 正确性：修复连续发送测试把空输入禁用误认为运行未结束的问题；修复编辑/重新生成使用旧上下文的检查；修复无文本模型的生图历史默认被设置面板遮挡。旧普通文本执行避免新增异步能力解析，原回归保持通过。
2. 可读性：参数策略、技能工具、图片画廊及下载分别放在小模块，复用会话解析及媒体导出；不建立无需求的通用插件管理框架。
3. 架构：React 只触发注册执行器，模型请求与凭据仍在主进程网关。保留既有 TXT 输出、项目媒体落盘及导入重映射，兼容旧节点。
4. 安全：工具 schema 只开放提示词，供应商/模型/项目/质量由应用决定；不读取任意技能路径或执行脚本；附件不接受外部 URL 或本机文件 URL；工具错误及日志对提示词脱敏，不提交数据库或凭据。
5. 性能：每轮最多一次图片提交，文本工具链限制步数；缩略图限制显示尺寸，历史文本压缩保留附件，不向文本模型发送图片二进制。没有新增逐帧日志或自动付费重试。

## 边界

本次实现文字生成图片，不包含图片编辑、任意技能安装和第三方文本模型工具支持保证。图片取消的远端状态可能未知；自动调用取消后的晚到图片可能只保存到项目资产。媒体导出沿用既有 UI IPC，完整 trace 缺失时明确标记关联缺失。详情见功能规范和日志覆盖清单。
