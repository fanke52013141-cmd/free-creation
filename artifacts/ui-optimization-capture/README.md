# Canvas Studio 节点 UI 截图

采集时间：2026-09-23。界面操作使用隔离的临时 Electron 数据目录；未打开或修改用户真实项目。视频生成按要求跳过。

## 目录与截图

- `nodes/<node-type>-<label>/01-default.png`：节点初始卡片。
- `04-io-top.png` 和 `04-io-scroll-*.png`：输入输出说明侧栏首屏和滚动位置。
- `02-card-scroll-top.png`、`03-card-scroll-bottom.png`：节点自身内容有滚动时的首尾画面。
- `05-run-details.png`：运行详情页。
- `06-run-success.png`、`06-run-failed.png`、`07-run-failed.png`、`09-run-result.png`：对应节点的真实运行状态截图。
- `07-workbench.png`、`08-*.png`：视频截取、抽帧和 P 图工作台，以及工作台交互状态。
- `scenarios/`：连线、多选、左对齐、打组、工作流运行中与运行完成画面。
- `manifest.json`：截图、节点状态和未采集节点清单。

25 个当前调色板节点中，除按要求跳过的视频生成外，其余 **24 个都各有一个节点文件夹**。视频截取和抽帧工作台使用本地视频夹具，P 图工作台使用本地图片夹具；截取与抽帧分别完成了本地运行。文本/代码成功、JSON/代码失败等状态均通过界面真实运行采集，没有用合成 DOM 伪造状态，也没有调用任何模型 API。

AI 对话节点使用专属对话窗口，不提供通用输入输出说明侧栏，因此保存了对话窗口画面。`video-audio` 已退役且不可创建；`script` 虽有节点定义，但不在当前调色板中，二者没有伪造可创建节点截图。尚未为依赖外部模型的节点触发模型运行状态。
