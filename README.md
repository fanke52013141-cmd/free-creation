# 无限画布 · 广告生产工作流平台

> 一个**无限画布式的广告生产工作流平台**。核心使命：把"AI 松散连接的广告生产过程"抽象成画布上的节点，让创作者能在一张自由画布上发散创作，并把成熟流程固化为可复用的工作流。

## 核心理念

- **双态模型**：发散态（自由创作，tldraw 式白板）↔ 固化态（封装成可复用工作流）。进入画布默认是发散态。
- **课程 → 章节 → 项目**三级层级，每个项目 = 一张无限画布。
- **节点 vs op 铁律**：变换（切分/截帧）是 op，创造（生成图片/视频）是独立节点。
- **三种关系**：数据依赖（唯一传数据）/ 流程连线 / 呈现绑定。
- **数组扇出**：输入是数组时，下游节点自动对每个元素各跑一次（批量生产核心）。

## 技术栈

React 19 + TypeScript + Vite 8 + tldraw 5.3.2 + Tailwind CSS v4

## 本地开发

```bash
cd app
pnpm install
pnpm dev      # 启动开发服务器（默认 http://localhost:5173）
pnpm build    # 构建生产产物
```
